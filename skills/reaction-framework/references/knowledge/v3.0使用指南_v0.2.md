## 一、使用指南是什么

v3.0 反应模式工作坊有一系列文档(工具 A / 工具 B / 工具 C / 四大模块 / 诊断路径 / 个性化分支 / 元规则 / 主文档)。每份文档都说明"我是什么"。

但用户的真实使用场景是**跨文档的、从具体状态出发的、问题驱动的**——你不会先把所有文档读完才开始用,你会从"我现在 X 状态"开始。

这份指南就是把"v3.0 提供什么"和"用户当下需要什么"对接起来。

**它不教 v3.0 的内容**——内容在各份文档里。它教**如何在 v3.0 里找到当下需要的东西**。

## 二、如果你完全是新人:从哪里开始

**从工具 C(反应日志)开始。每天 / 有触发时记几行。坚持几周。**

不需要先读完所有文档,不需要先决定"要做哪个模块",不需要先理解架构。

工具 C 是最低门槛的入口:

- 一行字也行
- 不每天写也行
- 没触发的日子可以不写
- 不评分,不打卡

工具 C 自然让你的识别力开始累积。等几周后你想"我要不要更系统地做",再考虑模块一。

如果你想了解 v3.0 的整体哲学,你已经在读对的文档了——继续往下看就行。其他文档需要时再翻。

## 三、按状态分的多入口导航

下面按用户当下可能的状态分了 7 个入口。**找到最像你当下的那一个**,跳过其他。

### 入口 3.1:"我刚被触发了"

**子状态判断:**

**A. 还在峰值中(身体强烈反应、语言破碎、有立刻做某事的冲动):**

→ **用工具 A 第一段**(急性止血,核心五动作)

不要在这个状态读其他文档,不要试图"理解"发生了什么。先止血。

**B. 峰值过去了 / 已经过去几小时(语言成形,情绪还在但不失控):**

→ **如果你有 30 分钟以上 + 私密空间:用工具 A 第二段**(回身体 → 深潜 → 接受)

→ **如果你没时间空间:不要勉强做工具 A 第二段**。先做工具 C 的最低记录(第 1 题 + 第 4 题),等有时间再做穿透工作。

**C. 触发已经过去几天:**

→ **写工具 C 的日志**(可以答完整 5 个问题,因为有距离了)

→ **如果还想做穿透工作:也可以做工具 A 第二段**(虽然过了几天,如果感受还在身体里,依然有效)

### 入口 3.2:"我想系统训练"

**子状态判断:**

**A. 完全没开始过任何系统训练:**

→ **从工具 C + 模块一开始**

具体步骤:
- 先用工具 C 几周,建立日记习惯
- 然后读模块一文档,看自己当前在阶段一二的哪个状态
- 模块一的训练就是工具 C(主载体)+ 身体信号识别 + 情绪命名

**不要一上来同时开始所有模块**——会撑爆。模块二要求模块一到阶段二,模块三要求模块一到阶段三 + 模块二到阶段二三,模块四要求模块二到阶段二。先做地基。

**B. 模块一已经到阶段二三,想进模块二:**

→ **读模块二文档**

具体步骤:
- 模块二的核心载体有两版:工具 A 第二段(急性版)+ 日常深潜接受(日常版)
- 急性版触发后用,日常版每周 1-3 次
- 加身体进入练习(每天 3 分钟)+ 接受微练习(每周几次)

**C. 模块二已经到阶段二三,想进模块三:**

→ **读模块三文档**

具体步骤:
- 模块三共用工具 C(选择层扩展用法)
- 加候选观察练习(每天日常小决策)+ 质感识别练习(针对最近的反应)
- **不要追求"做新选择"**——模块三的工作是看见和质感分辨,不是强迫做不同的事

**D. 模块二已经到阶段二三,想做并行的建设力训练:**

→ **读模块四文档**

具体步骤:
- 模块四是和模块一二三**并行运作的另一条路径**(建设主导),不是模块三之后的更高阶
- 硬前提:模块二至少阶段二
- 模块四的核心载体是"内在确信感的日常练习"(每天 3-5 分钟),加三个横向构件
- 服务的具体场景:外部消极话术 / 攻击性定义 / 诅咒式预设的不被自动覆盖

**模块三和模块四不是先后关系。** 可以同时做(只要模块二到位),也可以只做其中一个 —— 取决于你当前的核心诉求是"触发后的当下回应选择"(模块三)还是"还没被外部触发之前的内在结构建设"(模块四)。

**E. 你想知道按你的类型做训练有什么重点:**

→ **读两份个性化分支:**
- 按生存策略的冒险方向(主要服务模块三)
- 按反弹主导类型的训练重点(服务三大模块)

**这两份是参考,不是任务清单。** 看到自己有哪种生存策略 / 反弹主导类型在运作时,翻到对应章节看一下方向 + 重点 + 防滑。

### 入口 3.3:"我想做日记"

→ **直接看工具 C 文档**

工具 C 是开放式日记,不是结构化填表。即使你已经有日记习惯,工具 C 也只是让你在已有的日记里加一个"反应笔记"视角,不要求换日记媒介。

如果你想直接开始,工具 C 的最低门槛:

- 触发发生后,写"今天什么事触发了我"(第 1 题)+ "多久恢复的"(第 4 题)
- 一行字也行
- 一周 2-3 次就够

更详细的(5 个参考问题、月度回看、防滑设计)等你需要时再看。

### 入口 3.4:"我想做冥想"

→ **看工具 B 文档**

工具 B 不是单一的冥想推荐,是**按你当前状态路由到对应的冥想类型**。所以你需要先识别自己当前是工具 B 7 种状态里的哪一种:

- 状态 1:情绪洪水 / 思维过载
- 状态 2:抗拒感强烈 / 对现实不接纳
- 状态 3:头脑停不下来 / 过度反刍
- 状态 4:急性创伤激活 / 身体强烈紧绷(**不自助,转介水老师**)
- 状态 5:反复反刍过去 / 困在旧场景
- 状态 6:空洞感 / 存在感薄弱
- 状态 7:一般性日常练习 / 没有特定触发

工具 B 文档对每种状态推荐对应的冥想类型 + 强身体通道(路径 A)和弱身体通道(路径 B)双路径选项。

**特别注意:** 状态 4(急性创伤激活)不要自助处理冥想,直接找水老师线下专业身体工作。

### 入口 3.5:"我卡住了"

**子状态判断:**

**A. 卡在某个具体的训练里(模块一二三四的具体环节做不下去):**

→ **看对应模块的"防滑设计"章节**

每个模块都有 5-8 条防滑,大部分卡点在这里能找到。

→ **如果防滑里没有,看诊断路径文档的"层二训练诊断"**

诊断路径对每个模块都列了常见卡点 + 结构性卡点(表面卡在 X,实际是 X-1 没到位)。

**B. 反复同一种触发,处理几次都没改变:**

→ **可能是结构性卡点。看诊断路径"结构性卡点"那一节**

常见情况:
- 你以为是模块二穿透不下去,其实是模块一识别还不稳
- 你以为是模块三选择做不出,其实是模块二接受没到位
- 同一个反应模式需要被反复穿透多次,不是"一次不行就是没用"

**C. 反应模式没减少,觉得整套训练没用:**

→ **看元规则文档的第二章(悖论)**

很可能你在用反应模式的方式做 v3.0(应该 / 必须 / 我必须减少 / 我又失败了)——这本身就是悖论发作。

→ **同时看元规则文档第 3.3(完成感)**

也可能你的"没减少"判断来自头脑而不是身体——具体的某些反应模式可能真的有变化,但你用"必须全部消失"的标准衡量。

**D. "我接受不下去":**

→ **回到接受工作 + 启用不妖魔化抗拒机制**

具体说:
- 接受工作里"接受不下去"这个体验,几乎一定意味着升起了新的反应 —— 自责 / 羞耻 / 对抗 / 失望等
- **这些升起的本身是接受工作的下一层**,不是失败的证据
- 把每个升起的当作新的接受对象,继续接受工作

详细机制见工具 A 第二段接受段、模块二日常深潜接受第三步、元规则文档第 3.5 节。

更详细的常见问题展开见第五章"关于穿透 / 接受"分类。

**E. "我看清楚了但不能动":**

→ **判断是不是觉察 vs 建设的错配**

具体说:
- 如果你已经反复看见某个外部消极话术对你的影响,但仍然每次都被覆盖 —— 这可能是建设工作误用觉察方法
- 觉察工作处理已经存在的反应,建设工作建立还没被接管的内在结构
- 如果你的诉求是"不被某类外部输入自动覆盖",这是建设工作,看入口 3.7

详细判据和错配处理见元规则文档第四章。

### 入口 3.6:"我想停一下"

→ **看元规则文档第三章(评估完成)**

"想停一下"在 v3.0 里有三种完全不同的性质,先识别你属于哪一种:

**A. 累了 / 没动力 / 提不起劲(中性完成感):**

→ **暂停几周,不要"决定停止"**。睡眠、压力、季节性都会让训练容量下降。等状态恢复再回来。

期间如果发生急性触发,工具 A 还可以用;其他不强求。

**B. 某一层的工作真的有变化,感觉这块"够了"(健康完成感):**

→ **认可这个变化**。这一层告一段落不等于整体练完——你可以暂时不深挖这一块,做别的或者休息。

**C. 头脑判断"我练完了"+ 想彻底关闭(危险完成感):**

→ **慢动作回到具体体验**。问自己:身体上现在感觉是什么?这种"练完"的感觉,是来自身体真实的变化,还是来自头脑的判断 / 对更深工作的逃避?

如果发现是逃避,**也不强迫继续**。v3.0 不强迫任何人做任何事。但 agent / 你自己可以诚实承认:"我在逃避,但我现在选择暂停"——比"我练完了所以我不需要"更接近真实。

### 入口 3.7:"我想建立内在确信感 / 我不想被外部消极话术影响"

这是建设主导路径的入口。和入口 3.2 的训练不同,这里你不是想"系统训练所有能力",而是有一个具体的建设诉求。

**先做一个判断:你的诉求是不是建设工作清单内的?**

建设工作清单(理论框架第三章前置说明立的)只包含三类:

- 内在稳定参照点的建立
- 被消极预设植入时的免疫力
- 身体进入的能力(已在模块一二实操化)

**如果你的诉求不在清单内**(比如"想改善亲密关系冲突""想处理工作压力""想松动核心信念"),不是模块四的工作。看入口 3.5 卡住或转介到对应资源。

**如果在清单内,继续看子状态:**

**A. 我从来没做过相关工作,从容场景下想开始建立内在确信感:**

→ **从模块四构件一(内在确信感的日常练习)开始**

具体步骤:
- 每天一次,3-5 分钟,从容场景下做(早上起床 / 刷牙 / 睡前都行)
- 路径 A 身体通道或路径 B 语言通道,选对你顺的那条
- 关键句式:"此刻我能说一句关于自己的、我自己确定的事吗?"
- 第一句冒上来、自己确定是真的、不需要外部确认的话,就是那一句
- **不评价"够不够深刻"** —— "我此刻坐在这里"和"我是个温柔的人"在练习上等价

**前提检查:** 模块二要至少在阶段二。如果你还在模块二阶段一,或者还没做过模块二,先做模块二再来。**模块四不是入门路径**。

**B. 我已经被某句消极话术覆盖了几天才识别到,想做事后回看:**

→ **做模块四构件二(消极话术着陆点的识别练习)**

具体步骤:
- 回想最近一次让你不舒服的对话(不需要重大冲突,日常的小贬损就行)
- 答三个问题:那句话是什么形态?那一刻你身体里发生了什么?现在回看,是关于你的真相,还是别人的判断?
- 如果你已经被覆盖了几天,那几天里的感受需要先做模块二的穿透接受,然后再做这个回看练习

**几天的覆盖期里产生的反应**(自责 / 麻木 / 对自己的怀疑等)走模块二,**着陆点本身的回看**走模块四。两个是不同工作。

**C. 一句话冲击当下我就想做不被覆盖处理:**

→ **做模块四构件三的三步顺序**

具体步骤:
- **第一步:识别** —— 那句话冲击当下,问自己:"我身体里现在有什么?"
- **第二步:接受** —— 无论身体里是什么,作为新对象启用不妖魔化抗拒(它在这里,我也在这里;抗拒升起也在这里;不修复)
- **第三步:区分** —— **只有当第二步的感受真的被允许之后**,才做"那句话是 ta 的判断,不是关于我的真相"的区分

**关键陷阱:** 跳过第二步直接做第三步,是在压抑(理论框架 5.6 误区二)。即使第三步看起来"奏效"(对方话术好像没影响你),那是压抑,不是建设。

**当下版三步顺序是模块四阶段三的工作,不要在阶段一二就用这个版本。** 阶段一二做事后版三步顺序(几小时之后再做完整三步)。

## 四、典型实操路径示例

下面 5 个示例展示 v3.0 在真实使用场景里如何串起来。**不是规定的路径,是参考的画面。**

### 路径示例 A:从急性触发到训练入门

**场景:** 你和伴侣大吵一架,你冲出门外,在咖啡馆里坐着,胸口发紧,手在抖。

**实操路径:**

1. **当下(咖啡馆里):用工具 A 第一段**——核心五动作止血。不分析谁对谁错,先稳。
2. **30 分钟后(回到家有自己的房间):用工具 A 第二段**——回身体 5 分钟 + 深潜 10-15 分钟 + 接受。可能下到"我又被忽视了"或类似的底层感受。
3. **当晚:写工具 C**——不需要 5 题都答,写"今天什么事触发了我"(第 1 题)+ "反应下面是什么"(第 3 题,因为你刚穿透过)+ "多久恢复的"(第 4 题)。
4. **接下来一周:继续工具 C**——其他没触发的日子也可以记一行,或者完全不记,看自己。
5. **一个月后:做第一次月度回看**——发现你和伴侣的冲突模式可能反复出现。这是开始考虑系统训练的信号。
6. **下一步:开始模块一**——读模块一文档,看自己当前在哪个阶段(可能是阶段一种子期),按模块一的训练路径继续。

**关键点:**

- 一次触发的处理(步骤 1-3)不依赖系统训练
- 系统训练(步骤 4-6)是从一次触发自然延伸出来的
- 没有"我要做完整套 v3.0"的压力——每一步都是当下能做的事

### 路径示例 B:从工具 C 月度回看到模块二开始

**场景:** 你用工具 C 三个月了,最近一次月度回看发现:每次工作上被否定,你的反应都很大,而且事后好几天才能消化。

**实操路径:**

1. **回看时识别模式**:"工作被否定 → 反应大 → 几天才恢复"是一个稳定的反应模式
2. **判断当前阶段**:你能事后(几天后)识别到反应,基本到模块一阶段二。能识别"反应下面是什么"(被看轻 / 不被认可),颗粒度也开始细化
3. **开始模块二**:读模块二文档,知道核心载体是工具 A 第二段(急性版)+ 日常深潜接受(日常版)
4. **下一次触发(下次工作被否定):**用工具 A 第二段处理。可能下到"我永远不够好"那种底层感受
5. **同时开始日常深潜接受**:每周 1-2 次,15-20 分钟。找当下身体里还在的小不舒服(不必触发级)做深潜
6. **每天 3 分钟身体进入练习**:让自己习惯"住在身体里"
7. **几个月后**:工具 A 第二段做了多次,同一个底层感受("不够好")反复出现——这是正常的,每次释放一层
8. **逐步过程**:几个月后你可能发现工作上被否定的反应强度在降。模块二开始进阶到阶段二三

**关键点:**

- 模块二的开始是从工具 C 的月度回看自然引出的,不是凭空决定
- 工具 A 第二段在模块二训练里继续被使用——它是模块二的"急性版核心载体"
- 同一个反应模式(被否定)被反复穿透,是 v3.0 的常态,不是失败

### 路径示例 C:模块三阶段三的内在选择工作

> **这是成熟阶段的示例。如果你刚开始用 v3.0,这个示例展示的是几年后可能的状态——可以跳过,等你实际到这一步时再回来看。**

**场景:** 你已经做了较长时间的 v3.0,模块一二都到阶段三,模块三在阶段二三之间。最近你和母亲的一次电话:她又开始挑你的工作选择,你身体里立刻升起熟悉的"我必须证明自己"——但你这次没立刻反驳。

**实操路径:**

1. **当下识别**:模块一已经稳定,你立刻识别到"被触发了 + 旧模式是要证明"
2. **当下穿透**:不退出对话,在内在做一次小型的下潜——身体里这个紧的位置下面是什么?(可能是"我永远不够好让她满意")
3. **当下接受**:不修复这个感受,允许它在身体里
4. **当下识别候选**(模块三阶段三的工作):
   - 候选 A(旧模式):反驳 + 证明 + 讲道理(质感:紧、推、应该)
   - 候选 B:不接话,让她说完,然后转话题(质感:平、不抗、自然)
   - 候选 C:直接说"妈,我们换个话题吧"(质感:松、自然、不带火气)
5. **跟随涌现**:今天可能是 B 或 C 自然升起。跟随它
6. **不撤回**:挂电话后即使有"我应该再解释一下"的冲动,不打补丁(模块三防滑五)
7. **可能涌起的不舒服**(违反"做好女儿"的旧模式):用工具 A 第二段处理

**关键点:**

- 这个过程几乎全部发生在对话当下(几分钟内)
- 没有明显的"工具/模块切换"——模块一识别 + 模块二穿透接受 + 模块三选择**几乎是同步发生的**
- 这是 v3.0 训练成熟时的常态——三大模块不再是分离的训练,是融合的能力
- 工具 A 第二段在事后处理"违反旧模式后的不舒服"——v3.0 各部分的咬合在成熟阶段更紧密

### 路径示例 D:遇到反复触发的诊断和处理

**场景:** 你已经做了一个月模块二,但每次 X 类触发(比如被同事打断),反应都没变。你开始怀疑"是不是这套对我没用"。

**实操路径:**

1. **不立刻得出"没用"的结论**:很可能是诊断问题,不是训练问题
2. **看元规则文档第二章**:你是不是在用反应模式做 v3.0(我必须见效 / 我又失败了)?如果是,先识别这个悖论
3. **看诊断路径"层二训练诊断"**:你的"穿透不下去"是阶段卡点(阶段一种子期的常态)还是结构性卡点(模块一识别还不稳)?
4. **回工具 C 月度回看**:这一个月里,这种触发实际发生了几次?你的识别力对它的覆盖如何?颗粒度变细了吗?
5. **可能的发现**:
   - 发现 1:你以为穿透没用,实际上识别力是在变细的(从"被冒犯"变成"被看轻+不被尊重")——这是真进步,只是不是"反应消失"
   - 发现 2:你的反应模式有强烈的反弹主导特征(比如反应过度型),这种类型本身有特定的工作重点(参考个性化分支)
   - 发现 3:这种触发可能涉及更深的核心信念(理论框架 4.6),v3.0 范围内的工作有局限——可能需要找水老师做一对一
6. **根据发现调整**:不一定是"换方法",可能是"调整对'有用'的标准"+ "增加对应的工作重点"+ "知道边界在哪"

**关键点:**

- "反应模式没减少"很少是简单的"没用",通常是诊断/标准/边界的问题
- v3.0 的工作机制是螺旋的,反复看到同一个反应模式是常态,不是失败
- 知道 v3.0 的边界(4.6 / 创伤激活 / 严重困扰)在哪,才能合理判断什么时候找其他资源

### 路径示例 E:被攻击性定义击中的完整咬合

**场景:** 周末家庭聚会,父亲说了一句"你这种性格永远找不到对象",你愣住,饭没吃下去就回家了。

**这个场景涉及:工具 A → 模块二 → 模块四的咬合**。

**当晚 / 第二天:急性期处理(工具 A 第二段)**

- 你回到家还在峰值里(身体紧、想反复回放那句话、想立刻发消息回怼或想立刻避开父亲半年)
- 这是急性峰值期,**不做任何模块四工作** —— 模块四在峰值期上不去
- 用工具 A 第一段止血(核心五动作)
- **24 小时内不做任何重大决定**(不发反击消息、不决定半年不见、不做任何沟通)

**几天后:穿透接受(工具 A 第二段)**

- 峰值过去,身体能稳下来了。但那句话冲击产生的核心感受还在(可能是"我永远不被理解" / "我让父母失望" / "我注定孤独"等)
- 用工具 A 第二段做穿透接受。**这一步是模块四的前提** —— 这些核心感受没被穿透接受过,直接做模块四"那是父亲的判断不是我",会变成压抑(误区二)
- 接受过程中升起新反应(自责"我又这么脆弱" / 失望"我练了这么久还是被父亲一句话击垮"等),启用不妖魔化抗拒,把每个升起的当作新对象

**几天到一周后:回到模块四构件三(事后版三步顺序)**

- 接受工作做了几次,感受被允许之后,做模块四的三步顺序事后版:
  - **第一步识别**(回顾):那句话是什么形态?(攻击性定义 + 诅咒式预设的复合形态)
  - **第二步接受**(已经在前面做了):被冲击后产生的感受作为新对象,已经做了穿透接受工作
  - **第三步区分**:那句话是父亲的判断 —— 是父亲对"找对象"的焦虑、对自己人生选择的投射、对你的不接纳。**不是关于你的真相**
- 如果有内在确信感的累积,可以连接一句平时练过的话:"此刻我能说一句关于自己确定的事:我对 [X] 是认真的"

**长期:模块四日常练习(构件一)**

- 父亲这种攻击性定义不是孤立事件 —— 大概率是长期慢性贬损环境的一部分。建设工作的累积是对抗这类长期环境的真正路径
- 每天做一次构件一(内在确信感的日常练习),让"关于自己确定的事"在内在累积成结构
- 月度回看(构件四)看趋势:这一类话术着陆的频率有没有变化?当下识别的能力有没有提高?

**这个路径展示的关键:**

- **顺序不能颠倒** —— 工具 A 在前,模块二在中,模块四在后。跳到模块四直接做"那是父亲的判断"会撞误区二压抑
- **不要在峰值期启用模块四** —— 峰值期是工具 A 的事
- **模块四的工作是长期的,不是单次"成功"** —— 一次三步顺序做完不等于"我以后不被父亲影响",建设力的累积需要时间

如果你的核心诉求是"不再被父母这种话术影响",这是模块四长期建设的工作。不是一次三步顺序能解决,但每次做都在累积。

## 五、常见问题索引

按问题分类。每条:**问题 → 简短回答 → 详细查阅位置**。

### 关于开始

**Q:我从哪里开始?**
A:工具 C(反应日志)。详见本指南第二章。

**Q:我需要先读完理论框架吗?**
A:不需要。理论框架基础有帮助,但不是前提。v3.0 是实操系统,从做开始,不从读开始。

**Q:我应该先读哪几份文档?**
A:主文档第九章(5 分钟)+ 工具 C 文档(15 分钟)就够开始。其他文档需要时再看。

### 关于工具 C / 日记

**Q:我没有日记习惯,工具 C 适合我吗?**
A:适合。工具 C 的最低门槛是"触发后写一行"。详见工具 C "起步门槛"节。

**Q:我两周没写日志了,要不要从头开始?**
A:不需要。工具 C 允许任意中断和重启,不累积"失职"。详见工具 C 防滑三。

**Q:我每次写完都觉得自己又在反弹,怎么办?**
A:这是日志变成新批评者的信号。不要继续这种写法,记一句"今天我用日志打自己了"就够了。详见工具 C 防滑一。

### 关于触发处理

**Q:我刚被触发了,该用什么?**
A:看本指南入口 3.1。简短答:在峰值用工具 A 第一段,峰值过后用工具 A 第二段。

**Q:工具 A 第二段的"深潜"我做不下去怎么办?**
A:今天到哪是哪,留给下次。深潜不下去也是有效信息(说明今天容量到这里)。详见模块二防滑二 + 理论框架 4.5 障碍四。

**Q:我穿透到底层了,但接受不了,心里偷偷希望它快点过去,怎么办?**
A:这本身就是接受的工作。看见这个企图就够了,不要把"看见企图"变成新的评判。详见模块二防滑三 + 理论框架 4.9 不妖魔化抗拒。

### 关于穿透 / 接受

**Q:我接受不下去怎么办?**
A:接受不下去几乎一定意味着升起了新的反应 —— 自责 / 羞耻 / 对抗。这些升起的本身是接受工作的下一层,不是失败。把每个升起的当作新的接受对象,启用不妖魔化抗拒机制(理论框架 4.9)。详细机制见工具 A 第二段接受段、模块二日常深潜接受第三步、元规则文档第 3.5 节。

**Q:我做接受时升起新反应(羞耻 / 自责 / 对抗),这是失败吗?**
A:不是。这是接受工作必然出现的递归层(参见理论框架 4.9 不妖魔化抗拒)。处理方式统一 —— 把新升起的当作新对象。这个递归没有"完成",每一层升起的被允许了,这一层就告一段落。

**Q:接受工作里"看见就够了"和"启用不妖魔化抗拒继续"的关系是什么?**
A:"看见就够了"是理论框架 4.9 误区三立的精神 —— 看见自己在假装接受,看见本身已经是工作。"启用不妖魔化抗拒继续"是后续路径,如果用户愿意继续做下去,把"我在假装"作为新对象继续。两者并列,不互相替代 —— 单独看见已经是接受工作,不必强求继续(详见模块二防滑三、元规则文档第 3.5 节)。

### 关于训练阶段

**Q:我练了 X 个月,应该到哪个阶段了?**
A:**v3.0 不按时间评判阶段。** 看自己当前能做到什么(对照各模块的"能力标志"段)。"练了 X 个月该到 Y 阶段"是悖论发作的典型信号。

**Q:我能跳过模块一直接做模块二吗?**
A:不强行禁止,但你会撞墙——模块二的穿透需要识别力打底。识别力还不稳时,穿透的对象不清楚。

**Q:我在工作上识别得到,在家里识别不到,这是退步吗?**
A:不是。识别力高度情境化,不同场景的识别能力独立累积。家里反复出现的人/模式,识别需要更多次曝光。

### 关于卡点

**Q:我反复同一种触发,处理几次都没变,是不是没用?**
A:看本指南入口 3.5 子状态 B + 路径示例 D。多数情况是结构性卡点 / 标准错位 / 反应模式正在变但你用错指标看。

**Q:我做了半年,反应模式没什么变化,该怎么办?**
A:看元规则文档第二章(悖论)+ 第 3.3(完成感)。可能是用反应模式做 v3.0,可能是判断标准错位,可能确实需要其他资源。

**Q:我穿透到的底层感受太大,接受不住,怎么办?**
A:看工具 B 状态判断。如果是状态 4 级(急性创伤激活),转介水老师线下身体工作;如果是状态 1-3 / 5-7 级,工具 B 有对应身体工作推荐。

### 关于完成和停止

**Q:我练完了吗?**
A:v3.0 没有"练完",但有真实的"告一段落"。看本指南入口 3.6 + 元规则文档第三章。

**Q:我可以暂停吗?**
A:可以。v3.0 不要求连续性。详见本指南入口 3.6 子状态 A。

**Q:我感觉这一块练完了,但 agent 说"v3.0 不存在练完",怎么办?**
A:agent 的回答可能太机械。健康的"告一段落"是真实存在的,认可你的体验。详见元规则文档第 3.3(健康完成感)。

### 关于 Agent 协助

**Q:我必须用 agent 才能做 v3.0 吗?**
A:不必须。v3.0 的所有工具和模块都可以纯自己做。Agent 是协助,不是必需。

**Q:Agent 应该做什么、不做什么?**
A:每份文档都有"Agent 在 X 中的角色"章节。简短答:agent 做的是协助看见、卡点点破、防滑拉回、月度回看整理;不做的是替你做识别/穿透/选择/建设、给你阶段评分、催你练得更勤、把每句话都诊断分类。

**Q:我感觉 agent 在"教练化"我,怎么办?**
A:直接说。v3.0 的设计就是反对那种姿态的——这是 agent 偏离了 v3.0 的精神。

### 关于建设工作和工作类别

**Q:我应该做模块四吗?**
A:看你的诉求是不是建设工作清单内的:内在稳定参照点的建立 / 被消极预设植入时的免疫力 / 身体进入的能力。在清单内,可以做模块四(前提:模块二至少阶段二)。不在清单内,模块四帮不了 —— 看具体形态走其他模块或边界外资源(详见模块四防滑八)。

**Q:模块四是不是模块三之后的更高阶?**
A:不是。模块四是和模块一二三**并行运作的另一条路径**(建设主导),不是模块三之后的"更高阶"。模块一二三是事后路径(已发生的反应模式),模块四是前置路径(还没被接管的内在结构)。两条路径配合,反应模式工作才完整(详见主文档第三章 3.3、模块四第一章末尾)。

**Q:我想"建立强大不被影响的能力",这是模块四吗?**
A:小心。"必须永远不被影响"撞理论框架 2.6 全能自恋边界(三个识别标准之一是"对结果的绝对要求")。模块四能给的是大部分时候不被自动覆盖 + 被影响后能回来,不能给"永远不被影响"。带着"必须永远"诉求做模块四是错配,先回到 2.6 边界(详见模块四防滑五)。

**Q:模块四的核心载体在哪里?**
A:核心载体是"内在确信感的日常练习"(每天一次,3-5 分钟)。问句:"此刻我能说一句关于自己的、我自己确定的事吗?" 详见模块四构件一。

**Q:我看清楚了但不能动(觉察 vs 建设错配),怎么办?**
A:这通常是建设工作误用觉察方法 —— 你已经反复看见某个外部消极话术对你的影响,但仍然每次都被覆盖。觉察工作处理已经存在的反应,建设工作建立还没被接管的内在结构。如果你的诉求是"不被某类外部输入自动覆盖",这是建设工作,看入口 3.7。详细判据和错配处理见元规则文档第四章。

**Q:觉察工作和建设工作怎么区分?**
A:对象不同 —— 觉察工作处理已经存在的反应模式 / 底层感受 / 内在动力(看见 + 允许);建设工作处理还没被反应模式接管的内在结构 / 能力(反复确认 + 累积)。判据(参考,不机械套用):觉察信号"我又这样了 / 我看到了 / 为什么我总是";建设信号"我想稳一点 / 我不想被 X 影响 / 我希望建立 X"。判断不出来时,默认走觉察 —— 大部分场景觉察是主路径,建设只在清单内特定场景启用。详见元规则文档第四章 4.4。

**Q:我现在的诉求需要哪类工作?**
A:看你想处理的对象 —— 已经发生的反应是觉察工作(模块一二三),还没被接管的内在结构是建设工作(模块四)。同时存在两类需求是常见的(比如:被消极话术冲击产生了反应 → 反应是模块二三的工作 + 着陆点的不被覆盖能力是模块四的工作)。

**Q:Agent 给我建议时方向不对,我怎么知道?**
A:看你的体验。Agent 在做错配时常见信号:你诉求建设但 agent 一直让你"看见"(陷入"看清了但不能动");或者你诉求觉察但 agent 跳到"建立新模式"(觉察变成对抗)。直接告诉 agent 方向不对 —— v3.0 的设计就是允许用户校准 agent。详见元规则文档第四章 4.5。

### 关于个性化

**Q:我应该先确定我的生存策略 / 反弹主导类型再开始吗?**
A:不需要。生存策略和反弹主导类型是工作过程中自然识别出来的,不是开始的前提。两份个性化分支是后期参考。

**Q:我是混合型,该看哪一种?**
A:大部分人是混合型。在不同场景里识别哪种主导,就看那一种。两份个性化分支都强调"不挑出主导型,而是在不同情境里识别哪种策略在运作"。

## 六、v3.0 不是什么

为避免误解,**v3.0 的边界**已经在两处文档系统化处理过:

- **主文档第十章** —— v3.0 的克制(不扩散 / 不诊断 / 不评分 / 不催促 / 不替代 / 不假装练完 / 模块四的克制)
- **元规则文档第三章** —— "不存在练完"和三种完成感的区分

如果你刚开始用,只需要记住一句:

**v3.0 是工具,不是教义。** 它不是任务清单,不是诊断系统,不是替代水老师 / 心理治疗 / 医疗的方案,不涵盖理论框架的全部,也没有"练完"。详细边界查阅上述两处文档。

**模块四不是"刀枪不入训练"。** 模块四能给的是大部分时候不被自动覆盖 + 被影响后能回来,不能给"永远不被影响"。带着"必须永远"诉求做模块四撞理论框架 2.6 全能自恋边界(三个识别标准之一是"对结果的绝对要求")。详见模块四防滑五。

## 七、何时求助 / 何时找水老师

v3.0 是自助系统,有边界。下列情况寻求其他资源:

**直接转介水老师线下专业身体工作:**

- 工具 B 状态 4 级(急性创伤激活:身体强烈紧绷颤抖、过度警觉、解离感)
- 穿透到的底层感受太大、自助接受不住
- 反复 v3.0 工作后核心信念(理论框架 4.6)需要松动
- 重大冒险(辞职 / 分手 / 设根本性界限)需要陪伴

**寻求专业心理治疗 / 精神科:**

- 持续严重抑郁、自伤倾向、自杀念头
- 严重解离、严重物质依赖
- 急性精神症状(幻觉、妄想、严重躁狂)

**寻求医疗专业:** 身体健康问题 / 用药 / 涉及生命危险的状态

**水老师 vs 心理治疗师不互相替代:** 水老师做的是理论框架内在转化工作,心理治疗师 / 精神科做的是临床症状和精神病理的处理。严重情况下两者可能需要同时。

**关于"被外部影响"问题的转介判断:**

不是所有"被影响"问题都是模块四的工作。模块四只覆盖建设工作清单内的特定场景(内在稳定参照点 / 消极预设免疫力 / 身体进入能力)。

清单外的"被影响"问题按具体形态走对应资源:

- **亲密关系冲突 / 长期关系问题** —— 主要是模块二三的工作 + 关系层面工作。深层关系工作(部分理论框架第五章章节)在 v3.0 范围之外,转介水老师
- **工作压力 / 慢性消耗** —— 看具体形态。过度反应是模块二三,慢性消耗超出 v3.0 范围,需要边界外资源
- **原生家庭长期问题** —— 慢性贬损话术的免疫力是模块四,核心信念松动是理论框架 4.6 的工作(明确划在 v3.0 范围之外),转介水老师 / 自学
- **社会舆论 / 泛焦虑** —— 特定攻击性定义着陆是模块四,泛焦虑超出 v3.0 范围

详见模块四防滑八。

详细的转介判断和 agent 处理方式,参见**诊断路径文档第四部分"v3.0 边界以外的工作"**。

---

**一般情况下,自助 + agent 协助足够:** 日常的反应模式工作、一般强度的触发、模块训练的常规进展、月度回看,以及"我应该练什么 / 怎么开始 / 我卡在哪"这一类问题。

## 八、最后一句

v3.0 是工具,不是教义。

你不是要"做完 v3.0"。你不是要"成为 v3.0 训练有素的用户"。你不是要"按 v3.0 的标准衡量自己"。

你只是要**在你被反应模式困扰时,有一套可以用的东西**——能让你看见、能让你穿透、能让你慢慢有新的回应,能让你建立不被外部消极话术覆盖的内在结构。

用得多 / 用得少,做得勤 / 做得懒,中断了 / 又回来了——都允许。

**v3.0 的成功标准不是你执行得多完整,是你的反应模式有多少减少。** 而这种减少本身,是慢的、反复的、不可衡量的、要在月年尺度才能看出的。

所以:

- **从今天开始**(不要"等准备好")
- **从最小处开始**(工具 C 的第 1 题)
- **持续就好**(不必密集)
- **遇到问题查这份指南**(找到对的入口和文档)
- **遇到 v3.0 解决不了的问题找水老师 / 专业资源**(知道边界)

地基(模块一)有多深,工程(模块二)就能盖多稳。
工程(模块二)有多稳,顶上(模块三)就能多自由。
旁边的支撑结构(模块四)有多扎实,整个建筑就有多耐风。
但这些都不是目的——**目的是你不再反复被同一个反应模式撞回原地**。

走多远 / 怎么走 / 走多久,交给你和你的生活。
