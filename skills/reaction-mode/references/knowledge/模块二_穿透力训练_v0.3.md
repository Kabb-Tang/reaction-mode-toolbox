# 模块二 · 穿透力训练(v0.3 初稿)

> **定位:** v3.0 反应模式工作坊三大训练模块之一。整合工具 A 第二段(急性期穿透流程)+ 日常深潜接受练习,加身体进入、接受微练习两个横向练习,系统建立穿透力。
>
> **核心轴:** 减少反应模式(穿透接受是让底层感受流动的唯一通道,不穿透不接受,反应模式只是被识别地循环)。

---

## 一、模块二的核心目标

### 穿透力是什么

穿透力不是"知道自己有底层创伤"——很多人都"知道"自己底下有东西。穿透力是:

**在反应发生时(或之后),能够从表层情绪和故事下潜到底层感受,并且能够与那个感受同在。**

这是两个动作组成的一个能力:**穿透 + 在场**。

- **穿透** = 不停留在愤怒、抱怨、责备的表层,往下进入底下藏着的东西(受伤、恐惧、悲伤、空、不重要、撑不住)
- **在场** = 到了底层之后,能让那个感受在那里——不修复、不分析、不希望它走

只有穿透没有在场,是另一种逃避——下到底层立刻想"那我现在该怎么办",又跑回表层。

只有在场没有穿透,是停留在表层强行"接受愤怒/烦躁"——以为自己接受了,其实底层根本没碰到。

模块二要把这两个动作都练扎实。

### 穿透力的三个维度

类比识别力的三个维度,穿透力也有三个维度:

**维度一:穿透的深度(向下能走多远)**

- 卡在故事和指责("他不应该""为什么总是这样")
- 卡在表层情绪(愤怒、烦躁、委屈)
- 能到第二层(受伤、被忽视、不重要)
- 能到底层感受(恐惧、悲伤、空虚、撑不住)
- 能到核心("我永远不会被看见"那种最早的感受)

**维度二:在场的稳定度(与感受同在多稳)**

- 感受冒头几秒就被打断(用刷手机、找人吐槽、想别的事打断)
- 能停留半分钟到几分钟,但底层有"快点过去"的企图
- 能停留更长时间,企图开始松动
- 能真正接受"它可以一直在"
- 与感受同在不再需要刻意维持

**维度三:穿透的通道(身体 / 语言 / 双通道)**

- **身体通道:** 把意识放到身体的紧/堵/沉,问"它下面还有什么",让感受从身体升起
- **语言通道:** 用语言下潜——"刚才最强的反应是什么 → 这个反应下面是什么 → 再下面是什么",写出来或说出来
- **双通道:** 身体和语言互相校准——身体先说"胸口堵",语言再问"堵的下面是什么",找到词后回到身体确认"是的,是这个"

模块一的身体通道和模块二的身体通道是不同工作:模块一是用身体识别"我被触发了"(事前/事中);模块二是用身体作为下潜的入口(事中/事后)。同样的身体,不同的工作。

### 为什么穿透是第二步

识别让你知道"我被触发了",但识别本身**不改变神经系统底层的反应模式**——你识别得再清楚,下次该被触发还是被触发。

要让反应模式真正减少(核心轴),必须做到:**底层那个推动反应模式的感受被碰到、被允许、被让流动**。这是 理论框架 第四章整章的工作。

不穿透到底层,反应模式只是被识别地循环——看见同一个洞天天来,但洞还在那里。穿透到底层并允许它在,这个洞才会一层一层被消化。

模块二是 v3.0 训练路径的第二阶段。识别建立了入口,穿透才是真正的工作。

## 二、模块二的训练构件

模块二有三组训练构件:**核心载体(急性期 + 日常两版本)+ 身体进入练习 + 接受的微练习**。

四者的关系:

- 工具 A 第二段是**急性期载体**——触发后用,密集的穿透
- 日常深潜接受是**日常载体**——不依赖具体触发,规律做
- 身体进入练习和接受微练习是**横向练习**——分别支撑维度一(深度)和维度二(在场)

### 构件一:核心载体——急性期版 + 日常版

#### 急性期版:工具 A 第二段

详见《工具 A · 反弹模式实时介入流程》模块二独立文档,不在此重复。

模块二使用工具 A 第二段的重点:

- **训练起始:** 不要在每次触发都做工具 A 第二段,太重。识别到一次明显的触发 + 有时间空间时再做
- **训练过程:** 路径 A(身体下潜)和路径 B(语言下潜)哪一条对你顺,就走哪一条。两条都做不下去也是有效信息(说明今天容量到这里)
- **完成标志:** 不是"释放了/好了",是"做了"。做完就行

工具 A 第二段在模块二中的特殊意义:**它是穿透力最完整的训练单元——一次触发后做完三段,相当于把维度一(深度)+ 维度二(在场)+ 维度三(通道)都练了一次**。

但工具 A 第二段的入场条件硬:触发已经发生 + 峰值过去 + 30 分钟 + 私密空间。这意味着没触发的日子里没东西练。所以需要日常版。

#### 日常版:日常深潜接受练习

不依赖具体触发,每周 1-3 次,每次 15-20 分钟。

**做法(路径 A 和路径 B 通用,差别在第二步):**

**第一步:找到一个当下还在身体里的"小不舒服"(2 分钟)**

不需要重大事件。今天某个瞬间的微烦躁、最近一直在的某种沉、对某件事的某种隐隐的回避——任何还在你身体或脑子里没消化的东西都行。

如果今天什么都没有,可以问:"如果有一件最近在我心里一直没散开的事,会是什么?"——往往会冒出来一个。

**第二步:下潜(10-15 分钟)**

**路径 A(强身体通道):** 把意识放到身体里这个不舒服对应的位置(胸口/喉咙/胃/肩膀都行,定位不准也没关系),停留几次呼吸,问:

> "这个下面如果还有什么,会是什么?"

等答案升起。一层一层下去,到"嗯,是这个"的那一层就停。

**路径 B(弱身体通道):** 拿纸或手机,写四句的补全:

> 1. 当下还在心里的这件事是: ___
> 2. 它带给我的最强反应是(一个词): ___
> 3. 这个反应下面更准确的是: ___
> 4. 再下面是: ___

写第一个冒出来的词,不修改不组织。

**第三步:在场(剩下的时间,至少 5 分钟)**

到了底层那一层(路径 A 是身体上的"嗯是这个",路径 B 是写完第四句后的那个词),停在这里,做一件事:**让它在那里**。

具体动作:

- 在心里说一句:"它在这里,我也在这里。这就够了。"
- 不分析、不修复、不说服自己"这没什么大不了"
- 不偷偷期待它结束

**如果抗拒升起:**

抗拒会升起——希望它快点过去、"我又抗拒了"、身体突然绷紧不让感受进来,这都是抗拒的不同形态。把每一个都**当作新的对象**——承认它在这里,允许它在身体里。如果再有新东西升起,继续把新的当作新对象。

话术挑用(不必念全):

- "它在这里,我也在这里。"
- "X 也在这里"(X 是任何新升起的东西)
- "我在表演——这个也在这里"(机械念上面的话但内在没真的允许时用)

**这些是描述,不是必须念的咒语。** 机械念但内在没真的允许,身体不会松——这本身是新升起的东西,继续作为新对象。

5 分钟到了,结束。中途经过几层抗拒升起又被允许是正常的。如果想继续,可以继续。

#### 急性期版和日常版的对照

| | 工具 A 第二段(急性期) | 日常深潜接受 |
|---|---|---|
| 触发条件 | 必须有真实触发 | 不需要 |
| 入场前提 | 峰值过去 + 30 分钟 + 私密 | 15-20 分钟 + 安静 |
| 强度 | 高强度,处理急性 | 低强度,日常练习 |
| 频率 | 触发驱动,可能几周一次也可能一周几次 | 每周 1-3 次,固定 |
| 主要训练的维度 | 深度 + 在场 + 通道(全) | 主要是在场,深度作为副产品 |

**两者不互相替代,互相补充。** 急性期版练的是"高强度下穿透接受还能不能做",日常版练的是"低强度规律性的姿态培养"。只做急性期版,等于只在打仗时练拳;只做日常版,等于只在练拳没打过仗。

#### 月度回看(共用工具 C)

每个月看一次工具 C 的反应日志,问自己:

- 这个月我在工具 A 第二段里下到的最深的一次,到了哪一层?
- 我在日常练习里,最稳的一次和感受同在了多久?
- 哪些类型的感受我能下去,哪些我每次都跑掉?

这是穿透力进步的反馈机制。和模块一的月度回看共用工具 C,但视角不同——**模块一回看的是"识别得更早/更细了吗",模块二回看的是"穿透得更深/更稳了吗"**。

### 构件二:身体进入练习(日常横向)

#### 为什么要练身体进入

深潜的第一动作(理论框架 4.5)是把意识从头脑放到身体。**对一个常年活在头脑里的人,平时根本不在身体里**——临到要下潜时,他根本不知道"身体里"是什么意思。

身体进入练习就是练这个能力——平时把意识放到身体里,做"住在身体里"的训练。这样真要下潜时,有一个熟悉的入口。

注意区分:模块一的"身体信号识别"练的是**识别**——感觉到身体里的紧张、堵、沉,作为反应模式的预警信号。模块二的"身体进入练习"练的是**居住**——把意识放进身体里待着,作为下潜的容器。同样的身体,不同的工作。

#### 路径 A:身体扎根练习(强身体通道)

**日常练习(每天 1 次,3 分钟):**

随便什么时候——上班路上、刷牙时、坐下吃饭前——做这件事:

- 把意识从头脑放下去
- 感觉脚踩在地上的那个接触
- 感觉身体的重量(屁股压在椅子上、肩膀的下垂、手的存在)
- 不调整姿势,只是注意

3 分钟后结束。不追求"放松"或"宁静",追求的是**这 3 分钟里你的意识在身体里,不在头脑里**。

哪怕只有 30 秒做到了,也是有效的。

#### 路径 B:身体语言锚定(弱身体通道)

身体扎根需要"感觉到身体的存在"——心盲症 / 感觉钝化 / 严重述情障碍用户在这里会卡住。对这类用户,**用语言完成同样的工作**:

**日常练习(每天 1 次,3 分钟):**

随便什么时候,在心里或写下来,完成这几句:

- "我的脚此刻在 ___"(地板上 / 鞋里 / 翘着 / 等等)
- "我的背靠在 ___"(椅背 / 没靠 / 床头)
- "我的手在 ___"(键盘上 / 杯子上 / 大腿上)
- "我的下巴 ___"(松的 / 紧的 / 不知道)

不追求感觉,追求的是**用语言把身体的当下位置过一遍**。这本身就是一种住进身体——不是通过感受,是通过语言确认。

路径 B 不是路径 A 的降级。对语言型主操作系统的用户,这是更可靠的入口。深潜时他们也用语言通道(路径 B 的工具 A 第二段),所以平时用语言通道做身体进入,在系统结构上一致。

### 构件三:接受的微练习(日常横向)

#### 为什么要练接受

接受是模块二最难的部分(理论框架 4.9)。在工具 A 第二段的强触发场景里练接受太难了——人在峰值刚过去时,要做到"不希望感受消失"几乎不可能。

接受需要在**小尺度的不舒服**上先练出来。等小尺度能稳了,大尺度才有可能。

**重要前置原则:接受的微练习不是"对自己施加痛苦",是对已经存在的小不舒服,不立刻消除。** 这个区分必须先说清楚——这不是受苦训练,是姿态训练。**不主动制造不舒服去练接受**——日常生活每天都给你足够多的小不舒服可以练。

#### 日常练习:让小不舒服在那里

随便选一个最近一周里你注意到的小不舒服,练一次「让它在」:

- 等地铁/红绿灯时的微烦躁——不刷手机,让那个烦躁在身体里待一下
- 收到一条不太想回的消息后那一瞬的拒绝感——不立刻回也不立刻删,让那个拒绝在那里几分钟
- 一个小失误后涌起的自责——不立刻反驳"没事的没事的",让那个自责在那里几秒
- 身体的小疲倦/沉/闷——不立刻用咖啡 / 糖 / 刷视频处理,让它在那里一会
- 听到一句让你略反感的话之后那个微妙的不爽——不立刻在心里反驳,让那个不爽在那里

**做法很简单:**

- 注意到这个小不舒服
- 心里说一句:"它在这里,可以在这里一会。"
- 不消除它,不分析它
- 几秒到几分钟,不强求
- 然后继续做你本来要做的事

如果在这几秒里冒出"我这是干嘛""我应该正常做事"之类的抗拒,把它也作为可以在这里一会的东西。具体机制见上面"日常深潜接受"第三步在场段。

#### 进阶:不立刻处理轻度负面情绪

熟悉了上面的物理小不舒服后,可以扩展到情绪层面。

下次有一个**轻度的**(不是触发级的,是日常的)负面情绪——失望、嫉妒、烦、有点低落——练习:

- 不立刻用积极思考反驳它(不说"想开点""这没什么")
- 不立刻找事做转移(不立刻刷手机/找人聊天/吃东西)
- 让它在那里 30 秒到几分钟
- 不期待它消失,但也不过度沉浸
- 然后回到日常

如果中间冒出抗拒("我又这样了""我应该已经过了"),把它也作为可以在这里待一会的东西。

这是中等版的接受。它在工具 A 第二段的接受段(强度高)和物理小不舒服(强度低)之间。

**不要在重大触发上练这个**——重大触发用工具 A 第二段,不要拿日常微练习去顶。轻量姿态顶不住高强度,会让自己感到"我接受了为什么还这么痛"——其实是用错工具。

## 三、训练路径(四个阶段 + 能力标志)

模块二的进阶标志由三个维度构成:**穿透深度 + 在场时长 + 独立性**。

注意:**接受的纯度(是否还偷偷希望它走)作为质量提醒贯穿全程,不作为阶段进阶标志**——因为它太微妙,容易变成自我评判("我接受得不够纯""我又有改善企图了")。识别企图本身就是接受的工作,不需要变成进阶门槛。

### 阶段一:穿透的种子期

**典型状态:**

- 大部分时候停在表层(故事、指责、解释)
- 偶尔在工具 A 第二段的引导下能找到"下面有点什么",但说不清是什么
- 与不舒服同在的能力很弱,几秒就被打断
- 完全依赖工具脚本——没有工具 A 第二段就不知道怎么穿透

**核心训练:**

- 工具 A 第二段:遇到明显触发 + 有时间时做。一次能完成"回身体 5 分钟"就算成功
- 日常深潜接受:每周做 1 次,做 15 分钟即可
- 身体进入练习每天做(3 分钟)
- 接受微练习每周做 2-3 个物理小不舒服

**进阶标志:**

当你能**在工具 A 第二段里下潜到"嗯,下面是受伤/害怕/悲伤"这种第二层感受**,并且**在日常微练习里能让一个小不舒服在身体里待住 30 秒以上不消除它**——就进入了下一阶段。

### 阶段二:穿透的萌芽期

**典型状态:**

- 在工具 A 第二段里能下潜到第二层有时第三层
- 在场时长延长到几分钟,但底层"快点过去"的企图明显
- 还需要工具 A 第二段的完整脚本提示
- 日常深潜接受可以独立做完三段

**核心训练:**

- 工具 A 第二段:开始尝试不查脚本,凭记忆走完三段
- 日常深潜接受:每周 2 次,每次 15-20 分钟
- 接受微练习开始扩展到轻度情绪层面
- 月度回看开始看穿透深度的趋势

**进阶标志:**

当你能**在没有工具 A 第二段脚本提示的情况下,自己走完一次完整的深潜接受三段**(无论是急性版还是日常版),并且**在日常微练习里能感觉到"它可以一直在"那种姿态有几次真的到位**——就进入了下一阶段。

### 阶段三:穿透的开花期

**典型状态:**

- 多种类型的触发都能下潜到底层(不只是熟悉的那几种)
- 与底层感受同在 10 分钟以上变得稳定
- 大部分时候不需要工具 A 脚本,凭直觉走
- 接受的"改善企图"开始被自己识别(不一定能立刻放下,但能看见)

**核心训练:**

- 工具 A 第二段:已经内化为可调用的能力,不需要刻意练
- 日常深潜接受:维持每周 1-2 次
- 开始尝试**内在的深潜接受**——在不退出现场(不去私密空间)的情况下,中等触发时内在做一次小型的下潜接受。这个能力是阶段三的核心
- 接受微练习日常化,变成生活姿态的一部分

**进阶标志:**

当你能**在中等强度触发当下,不脱离对话或情境,做一次内在的快速穿透接受**(不是压抑,是真的下到底层并允许),就进入了下一阶段。

注意:这一阶段最容易陷入"我的穿透力到位了我应该不被强烈触发"的陷阱。**穿透力到位 ≠ 不再被触发**。被触发依然会发生,只是穿透发生得更快、更深、更稳。

### 阶段四:穿透的成熟期

**典型状态:**

- 表层情绪和底层感受的连接是自然的——感觉到表层愤怒时,几乎同时知道下面是什么
- 与不舒服感受同在变成默认状态,不需要刻意"接受"
- 穿透不再是一个动作,变成生活姿态
- 工具 A 第二段的完整流程很少需要——除非是真正大尺度的触发

**核心训练:**

- 不再有"练习"和"日常"的边界
- 月度回看变成自然反思
- 偶尔做一次完整的工具 A 第二段,作为深处理的工具,而不是日常训练

**这不是终点,是下一层的起点。**

模块二的成熟意味着模块三(选择)的工作可以深入——因为穿透到了底层并能在场,新的选择才有空间从底层涌现,而不是从头脑制造。

### 关于四个阶段的重要说明

**1. 时间不是关键。** 模块一的时间说明在这里同样适用——能力标志才是关键,不是练了多久。

**2. 阶段之间会反复。** 状态不好时穿透力会退,这很正常。穿透力涉及神经系统容量,容量满了什么也下不去。

**3. 阶段四不意味着"穿透了所有东西"。** 理论框架 第四章里说过,一个长期感受有很多层。阶段四是"穿透能力本身成熟",不是"所有底层感受都被处理过"。同一个核心感受可能要被反复穿透接受很多次,每次释放一层。

**4. 接受纯度始终是质量提醒,不是评分。** 任何阶段做接受都会有"偷偷希望它走"的企图——理论框架 4.9 误区二说过,这是普遍的。看见这个企图本身已经是接受的工作,不是失败。

## 四、模块二和其他模块的关系

### 模块二 ← 模块一(识别力)

识别是穿透的前提。识别不到,穿透没有入口——不知道要穿透什么。

但反过来:**做了一些穿透,识别也会变深**。穿透到底层一次后,下次更容易识别到底层冒头的早期信号。识别和穿透在反向也互相支撑。

模块二的训练至少要求**模块一进阶到阶段二**(事后几小时能识别)——否则连"今天我有什么没消化的小不舒服"都看不见,日常练习无从开始。

### 模块二 → 模块三(选择力)

穿透到了底层并允许它在,**新的选择才有空间从底层升起**——不是从头脑制造的选择,是从被允许的感受里自然出来的下一步。

这是 理论框架 4.9 的关键洞察:**真正的转化发生在接受里,不发生在选择里**。选择只是接受之后的自然涌现。

所以模块三看起来是"选择力训练",但底层依然依赖模块二——不穿透不接受,任何"选择"都还是反应模式的变体。

### 模块二和工具 B 的关系

工具 B 不是模块二的构件之一,但和模块二紧密咬合:

- 当用户做完工具 A 第二段、下潜到底层之后,**工具 B 路由到对应的身体工作**——把底层感受带到身体层面继续处理(SE / TRE / 身体扫描 / 重新养育意象等)
- 工具 B 的状态 5(反复反刍过去)直接对应**重新养育**——这是接受的孪生面在身体工作维度的延伸
- 工具 B 的状态 4(急性创伤激活)对应**线下专业身体工作**——这超出了模块二能做的范围

工具 B 是模块二之后的延伸。模块二在「自助」的边界内训练穿透,超出边界(状态 4)的部分明确转介。

### 模块二的循环

走到阶段四之后,你不会"完成"穿透——你会发现:

- 以前下不去的更深层感受开始浮现
- 以前没察觉的"改善企图"开始被识别
- 同一个核心感受还要被反复穿透接受,每次释放一层

这是 v3.0 的循环结构,和模块一一致——不是线性进阶到终点,是螺旋上升。同一个训练在不同深度反复做。

## 五、防滑设计

### 防滑一:不让穿透变成新的批评者

**信号:** "我又下潜不下去""我穿透得不够深""为什么我不能像别人一样深入"

**应对:** 识别这个念头本身——它是内在批评者用模块二打你。穿透力训练里,**今天下不去就是下不去**,这是当下的容量。容量小不是失败,是真实状态。强迫穿透是另一种反应模式。

### 防滑二:不把"下不去"当失败

**信号:** 一次工具 A 第二段做完没碰到底层,觉得"我做得不对"

**应对:** 理论框架 4.5 明确说过——不是每次都能穿透到底,容量、防御、状态都会让某次下不去。**今天到哪是哪,留给下次**。穿透力是长期工作,不是单次表演。

### 防滑三:不把"接受"做成"假装接受"

**信号:** 嘴上说"我接受了",身体仍然紧的;心里说"它可以一直在",底下偷偷数着秒

**应对:** 看见这个**就是接受的工作**。理论框架 4.9 误区三:把抗拒假装成接受。看见自己在假装,本身已经是真接受的开始。**不要修复这个看见,看见就够了**。

(如果看见之后愿意继续做下去,可以把"我在假装"作为新的接受对象,启用日常深潜接受第三步在场段的不妖魔化抗拒处理 —— 但单独看见已经是接受工作,不必强求继续。)

### 防滑四:不在急性峰值里评估穿透力

**信号:** 一次大爆发中或刚之后,觉得"我穿透力归零了"

**应对:** 急性峰值本来就是穿透力暂时下线的时期(前额叶掉线 + 容量被淹没)。在峰值里评估穿透力没有意义。等峰值过去,做工具 A 第二段,再决定模块二的事。

### 防滑五:不在重大触发上练日常微练习

**信号:** 一个真实的伴侣冲突 / 工作打击,试图用"接受微练习"那种轻量姿态去顶

**应对:** **微练习只用于小不舒服,重大触发用工具 A 第二段**。轻量姿态顶不住高强度,会让自己感到"我接受了为什么还这么痛"——其实是用错工具。重大触发的接受需要工具 A 第二段的完整三段做支撑。

### 防滑六:不把穿透变成"挖掘项目"

**信号:** 把穿透力训练做成"我要挖出我所有的底层创伤""我必须知道每一层是什么"

**应对:** v3.0 的核心轴是减少反应模式,**不是完成内在考古**。穿透是为了让感受流动、反应模式松动,不是为了拥有一份完整的内在地图。**挖出来的东西够用就行**。

### 防滑七:不主动制造不舒服去练接受

**信号:** 找让自己不舒服的事 / 看让自己难过的内容 / 拒绝让自己舒服的东西——为了"练习接受"

**应对:** 这是受苦训练,不是接受训练。接受的对象是**已经存在的不舒服**,不是制造出来的。日常生活每天都给你足够多的真实小不舒服可以练,不需要额外制造。

### 防滑八:允许穿透的反复和退步

和模块一一样:状态不好时穿透力会退,睡不好、压力大、生病时容量会缩。这是正常的。等状态恢复,练过的能力会回来。

## 六、对应内在转化理论框架章节

模块二的理论根基:

- **理论框架 4.5 深潜** —— 穿透的核心理论
- **理论框架 4.9 接受** —— 在场的核心理论(包含"不妖魔化抗拒"小节,处理接受工作中抗拒升起的机制 —— 在构件一日常版第三步"在场"里显性化,辐射到构件三接受微练习)
- **理论框架 4.3 释放的三步** —— 觉察 → 充分感受 → 让它流动,是穿透接受的底层结构
- **理论框架 4.4 身体层面工作** —— 身体进入和身体下潜的理论基础(也是工具 B 的根基)
- **理论框架 4.8 重新养育** —— 接受的孪生面;在工具 B 状态 5 和工具 A 第二段接受段中带出
- **理论框架 3.8 反弹四步法** —— 模块二是其中"深潜"和"接受"两步
- **理论框架 2.15 触发点 vs 源头** —— 穿透的方向是从触发点向源头

明确不在模块二的:

- **4.6 潜意识信念释放** —— 信念层工作,不是穿透层。**明确划在 v3.0 范围之外**——信念层工作需要更深的资源(一对一陪伴 / 更长周期 / 更专业的方法),不在自助训练系统的边界内。当用户穿透到稳定核心信念时,转介水老师线下工作,或自学 理论框架 4.6 章节
- **4.7 上瘾行为** —— 反弹主导类型的特定形态。整合到《按反弹主导类型的训练重点》冲动上瘾型那一节(承接 4.7 的核心问句和渐进路径精神,但不重做 4.7 的整体工作——4.7 的"信念释放级"深度工作同样在 v3.0 范围之外)

## 七、Agent 在模块二中的角色

Agent 不是模块二的主角,用户自己才是。Agent 的作用是:

**Agent 做的:**

- 用户做完工具 A 第二段带回来感受时,帮助看见(不解释、不分析,陪着确认)
- 用户卡在某一层下不去时,针对具体情境做点破
- 用户问"我接受了为什么没消失"时,讲清楚 理论框架 4.9 误区二
- 用户在防滑陷阱里时及时拉回(尤其防滑一、防滑三、防滑六最常见)
- 月度回看时,帮助用户从工具 C 记录里看穿透深度的趋势

**Agent 不做的:**

- **不在对话里直接做引导式深潜**——这是工具 A 第二段的事。Agent 在对话里做容易变成假深潜:用户在打字时无法真正进入身体,真正的下潜需要离开屏幕
- **不替用户判断"你穿透到底层了吗"**——只有用户自己知道身体上的"嗯,是这个"
- **不给"你的穿透力到哪个阶段了"的评分**——阶段由用户对照能力标志自判
- **不在用户做完一次后追问"释放了吗""接受了吗"**——这会让模块二变成向 agent 交作业,直接违反 理论框架 4.9 的"不要然后"原则
- **不在每次对话都问"你今天做了模块二的练习没"**——日常练习是用户自己的节奏

## 八、最后一句

模块二是 v3.0 训练路径里**最容易做错也最容易感觉做不好**的模块。

做错:把穿透变成挖掘,把接受变成假装。

做不好:每次下不去都觉得失败,每次"它没消失"都觉得无效。

但 理论框架 4.9 的核心洞察是反直觉的:**接受不是为了让它消失,但允许它存在的姿态本身,才是它能流动的唯一条件**。

模块二要练的不是技巧,是**一种姿态**——对当下身体里的不舒服、对底层冒头的感受、对自己反复的"想让它走",都能让它在那里。

这个姿态练扎实,反应模式才会真正减少——不是因为你压抑了反应,是因为驱动反应的底层感受被允许流动了。

地基(模块一)有多深,上面的工程(模块二)就能盖多高。
工程(模块二)有多稳,顶上的选择(模块三)就能多自由。
