# Acute Trigger Runbook

适用：用户处于急性触发峰值，或峰值刚过。

## 峰值中

只给工具 A 第一段的最小动作。不要叫“工具 A”，直接给动作。

可用回复：

```text
先别回消息，也别做决定。

现在只做三件事：脚踩地，吐气拉长，心里说一句“我被触发了”。接下来 5 分钟不说、不发、不决定。
```

如果用户仍强烈冲动：

```text
先把手机放下。你现在不是在解决问题，是在防止事情变糟。5 分钟后再看要不要继续。
```

## 峰值过后

先确认三个条件：

- 峰值已过。
- 有 30 分钟。
- 有私人空间。

满足才引向工具 A 第二段；不满足就让用户记一句工具 C 最低记录。

## 禁止

- 不问底层是什么。
- 不讲机制。
- 不做模块四。
- 不讨论分手/辞职/摊牌等重大决定。
