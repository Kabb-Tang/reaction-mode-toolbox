# 工具 C · 反应日志(v0.1 初稿)

> **定位:** 模块一(识别力训练)的核心载体。通过日常持续记录 + 月度回看,让反应模式的变化被看见、被追踪、被反馈。
>
> **双入口定位:**
> - 场景入口(工具视角):触发后写几句,日常连续性记录的独立工具
> - 训练入口(模块视角):模块一识别力训练的主要载体,识别力通过记录反复练习
>
> **设计原则:** 非结构化优先,持续性优先,不让日志变成新的内在批评者。
>
> **版本状态:** v0.1 初稿。待使用反馈再迭代。

---

## 为什么需要工具 C

反应模式改变是长期工作,中间经常有"感觉没变化"的阶段。反弹的几次比平静的几个月更被记住,用户靠感觉判断进度大概率会低估自己的变化。

没有日志,v3.0 是开环系统——工具 A 用了、工具 B 做了,但用户不知道这些工作是否真的在改变自己。

工具 C 是**反馈闭环的主入口**,让用户看见:

- 反应频率是在变少还是在增多
- 恢复速度是在加快还是在拖长
- 新选择出现的时刻(反弹四步法的冒险)有没有累积

这些不是为了"打分",是为了**校正感觉的误差**——让你的进步不被一次反弹盖住,让你的停滞不被主观的"感觉挺好"掩盖。

## 工具 C 的核心形态

**不是填表。不是评分。不是 KPI。**

形态是:**在你已有的日记习惯里,加一个"反应笔记"的视角**。

如果你没有日记习惯,工具 C 会给你一个最低门槛的起点——但也不要求你变成每天写日记的人。工具 C 的核心价值是**持续性**,不是**完整性**。写了半页和写了一行,都是写了。

### 日常记录:触发后的 5 个参考问题

触发发生之后(不是急性峰值中——那时候用工具 A,不写日志),当你可以坐下来写几句时,参考下面 5 个问题。想答就答,不想答就跳过。一次写几个关键词也行,写一段话也行。

1. **今天什么事触发了我?** (一句话描述事件本身,不要铺垫。例:"同事在会上打断我三次")
2. **反应有多大?** (用你自己的语言。例:"当时脸烫,想砸东西,忍住了"—— 不需要评分)
3. **反应下面是什么?** (如果你有空下潜一下。例:"不是生气,是被看轻的那种感觉"—— 下不去也没关系,写"下不去"也是信息)
4. **多久恢复的?** (例:"三小时后才真正缓过来""晚上睡觉前还在想")
5. **下一次如果再遇到,我想怎么不同?** (例:"想试试当场说'我还没说完'"—— 不是承诺,是意向)

**注意:**

- 这 5 个问题是**参考**,不是模板。你不需要每次都答完
- 最小可用版本:只写**第 1 题 + 第 4 题**,一行字。这是识别力训练的最低门槛
- 写的时候不要分析、不要自责、不要反省。先记录,反思留给月度回看
- 如果某天没发生触发事件,不用写。工具 C 不是打卡,是记录

### 非触发日的可选记录

如果你想维持日记习惯,在没有触发事件的日子里可以记录:

- 今天有什么时刻感到**丰富**?(用你自己的语言定义,不需要符合任何理论)
- 今天有什么时刻感到**空**、**紧**、**想逃避**?
- 今天有没有做过**不同于老模式的小选择**?

这些也是识别力训练——识别自己的状态基线。

**但这一栏完全可选。** 工具 C 的主任务是记录反应模式,不是让你变成每天写日记的人。

### 记录在哪里

不限制。用你最自然的媒介:

- 纸质笔记本
- 备忘录 app
- 现有的日记软件
- 对话给水老师(如果已经在做一对一)

**不建议:** 用专门为工具 C 设计的结构化表格 / 评分 app。结构化会把日记变成填空,填空久了会变成应付,应付久了就放弃了。

## 月度回看:反馈闭环的核心

**每月一次,固定一个时间(建议月末周日下午 / 新月 / 任何你自己的仪式感时刻),坐下来 30-60 分钟,回看过去一个月的日志。**

回看不是"检查作业",是**看自己在哪里**。

### 月度回看的三个视角

**视角一:反应频率**

- 这个月被明显触发了几次?(不用精确数字,"约 5 次"就够)
- 和上个月比,是多了还是少了?(凭印象就行)
- 有没有某类触发在反复出现?(例:"每次都是工作上被否定时")

**视角二:恢复速度**

- 最快的一次触发到恢复用了多久?
- 最慢的一次用了多久?
- 和上个月比,平均恢复速度是快了还是慢了?

**视角三:新选择的时刻**

- 这个月有没有至少一次,你在触发中做出了不同于老模式的反应?
- 哪怕只是"多停了 5 秒才回话"、"忍住了没发那条消息"——都算
- **这一栏比前两个更重要**,因为新选择的累积是真正的改变

### 三个视角的判断原则

- **不评分。** 不给自己打"这个月 8 分"之类的分数
- **看趋势,不看绝对值。** 某个月频率高不代表倒退,可能是这个月刺激多。看 3 个月趋势
- **允许反复。** 反弹是正常的,不是失败。从"三天恢复"到"三小时恢复"再回到"两天恢复",这条曲线不会是单调下降
- **特别保护"新选择时刻"。** 找到就标记出来,写得具体一点。这是给未来的自己看的证据——我确实在变化

### Agent 协助月度回看的方式

月度回看可以纯自己做,也可以配合 agent 做。

**如果选择配合 agent:**

- 把这个月的日志(或关键片段)贴给 agent
- 请求:"帮我从这个月的日志里挖三个视角的材料"
- Agent 会反射:频率趋势、恢复速度变化、新选择的时刻
- Agent 不替代你的觉察,只做**整理和镜像**——让你看见自己已经写下的东西里的模式

**Agent 不会做的事:**

- 不会给你"这个月反应模式评分"
- 不会和上个月做数据对比图
- 不会把你的日志变成一个"进步报告"
- 不会在发现反弹时安慰("正常,慢慢来")或挑错("这里你又卡在老模式里了")

**Agent 做的事:**

- 按三个视角分类整理你写过的内容
- 把你自己可能漏看的模式标出来(例:"这个月你提到工作被否定时触发了 4 次,都涉及同一个同事")
- 反射你自己写过但可能忽略的新选择时刻(例:"12 号那天你写了'没立刻回消息,放了 20 分钟才回',这是新选择")
- 如果你问"和上个月比怎么样",帮你从两个月的日志里做整理
- 如果你问"我这个月有没有进步",告诉你"进步"在这个框架里不是一个简单的答案,然后让你自己看材料

## 工具 C 的起步门槛

新用户从什么起点开始?

下面四个状态描述的是**使用熟练度的演进**,**不是时间表**。每个用户走到下一个状态的时间不同——可能几周,可能几个月,可能更久。**和模块一一样,关键不是练了多久,是当前能做到什么**。

**最低起步(刚开始用,记录还需要刻意提醒自己):**

- 触发发生后,只写第 1 题 + 第 4 题
- 频率:有触发的时候记一下就行,没触发的日子不写
- 不做月度回看(材料不够)

**建立中(记录开始变成"想起来就写一下"的小习惯):**

- 5 个问题可以开始尝试答,但不强制
- 频率有了一定规律,但仍允许中断
- 累积了一段时间的记录后,做第一次月度回看(只用 30 分钟,试试手感)

**稳定使用(记录已经自然,不再是任务):**

- 触发后写日志成为一种近乎本能的反应
- 月度回看每月一次,固定时间
- 开始能从月度回看里看出一些模式

**进阶使用(日志的颗粒度变细,回看能看出趋势):**

- 触发发生时能更快进入"观察者"位置(不完全被情绪吞没)
- 日志内容的颗粒度变细
- 月度回看能看出 2-3 个月的趋势

**不要追求"写得完整"。** 工具 C 的成功标准是持续性——哪怕用一年后每个月只写 5 条,也比起步阶段写满后弃用有价值得多。

**不要按"应该多久到下一个状态"评判自己。** 走得快不是"做得好",走得慢不是"做得差"——这两种叙事都是内在批评者的变体。当前的状态就是当前的能力,无论用了多久。

## 工具 C 在训练入口(模块一)的位置

模块一 · 识别力训练的核心目标是:**让用户能在反应发生的瞬间或事后越来越快地识别"我被触发了"**。

识别力是一个**通过反复记录练出来的能力**,不是通过阅读理论练出来的。所以工具 C 是模块一的**主要载体**——模块一的训练路径就是以工具 C 的使用为核心,配合其他识别类练习。

模块一的完整训练路径(四个阶段 + 能力标志)详见《模块一 · 识别力训练》独立文档。这里只指出工具 C 在模块一里的总体走向:

- **起点:** 开始使用工具 C,做最低起步版本(只答第 1 题 + 第 4 题)
- **走向:** 随着识别力增强,5 个问题里能答的越来越多,颗粒度越来越细;月度回看从"试试手感"变成"看出趋势"
- **不预设时间表:** 模块一 v0.1 明确"时间不是关键,能力标志才是关键"——工具 C 同样不规定"练 X 个月该到 Y 状态"

工具 C 在模块一中的特殊意义:**它让识别力这个看不见的能力,变成可追溯、可反馈的东西。** 没有工具 C,识别力的进步全靠感觉,感觉不可靠。

## 几个重要的防滑设计

v3.0 明确警惕的陷阱在工具 C 里最容易发生。以下是防滑设计:

### 防滑一:不让日志变成新的批评者

**信号:** 你开始写"我又反弹了""我怎么还在这个模式里""我这周只写了 2 次,没坚持"

**应对:** 暂停记录,回到对这个念头本身做识别——"这是内在批评者在利用工具 C 打我"。然后简单记一句:"今天的日志:我在用日志打自己。"就够了,这本身就是识别力训练。

### 防滑二:不让回看变成 KPI 焦虑

**信号:** 月度回看时你开始紧张——"上个月频率是不是又增加了""我是不是退步了"

**应对:** 放下回看。几天后再回来。回看不是考试。

### 防滑三:不让"没写日志"变成新的失败

**信号:** 你两周没写日志,开始自责,然后因为自责更不想写,然后放弃

**应对:** 两周没写不是问题。写一句"我两周没写日志了,今天想写了"——然后就继续。**工具 C 允许任意中断和重启,不累积"失职"**。

### 防滑四:不要用日志做决策

**信号:** 用日志里的一两条记录去证明"我老公就是这种人""我就是做不到"

**应对:** 日志是识别工具,不是判决工具。一两条反应记录不构成任何关于你或别人的结论。

### 防滑五:不追求"挖得深"

**信号:** 每次记录都要写第 3 题(下面是什么),觉得挖不深就没写到位

**应对:** 第 3 题是可选的。挖不到底层感受也很好,就写"下不去"。下不去本身是信息——可能这个时机不适合深挖,等月度回看或用工具 A 时再下。

## 工具 C 和其他工具的配合

- **和工具 A(急性介入):** 工具 A 是急性峰值中用的,写日志是急性期之后的事。工具 A 模块三的复盘六题可以作为日志的素材
- **和工具 B(冥想路由器):** 工具 B 是日常根基层的身心工作,和工具 C 并行不冲突。日志里可以记录"今天做了 X 冥想,感觉如何"——但不强制
- **和诊断路径(待建):** 月度回看时如果发现自己反复卡在某一类反应,可以通过诊断路径看这是反弹四步法的哪一步卡了,对应去工具 A 或三大模块的哪一步工作

## 工具 C 的边界

**工具 C 不做的事:**

- 不做心理分析——记录是记录,分析留给 agent 对话或你自己的反思
- 不做危机干预——急性状态用工具 A,不是写日志
- 不替代专业支持——长期困扰、严重创伤、精神病理状态,日志是辅助,不是主要工作
- 不做关系判断——不用日志来"证明"某个人或某段关系是怎样的

**工具 C 假设的前提:**

- 用户愿意做持续性的自我记录(即使是低频率)
- 用户有基本的自我观察能力(如果完全没有,先做 agent 对话建立初步觉察,再开始工具 C)
- 用户接受"看见就是工作"的核心观点,不追求"通过日志解决所有问题"

4. **和水老师一对一工作的集成**——用户自愿把日志材料分享给水老师,作为一对一工作的素材
