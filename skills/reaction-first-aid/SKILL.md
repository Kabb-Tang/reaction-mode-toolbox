# 急性稳定与身体路由

先读取 `references/core/runtime-contract.md`、`references/core/focus-lifecycle.md`、`references/core/progressive-session.md`、`references/core/safety-boundary.md` 和 `references/core/output-self-check.md`。

再按情况读取：

- 急性峰值：`references/knowledge/工具A_反弹模式实时介入流程_v0.2.md` 与 `references/knowledge/runbooks/acute_trigger.md`。
- 峰值后身体调节：`references/knowledge/工具B_冥想路由器_v0.2.md` 与 `references/knowledge/runbooks/body_regulation.md`。
- 即时危险、状态 4 或超出边界：`references/knowledge/runbooks/transfer_out.md`。

只提供当下最小稳定动作；不解释底层机制，不问创伤来源，不建议重大决定。状态 4、严重解离、自伤他伤或即时危险时停止自助路线并转介。
