# 模块一 · 识别力训练(v0.1 初稿)

> **定位:** v3.0 反应模式工作坊三大训练模块之一。通过工具 C 为核心载体,加上身体信号识别、情绪命名两个补充练习,系统建立识别力。
>
> **核心轴:** 减少反应模式(识别是减少反应的第一步,不识别无处下手)。
>
> **版本状态:** v0.1 初稿。待使用反馈再迭代。

---

## 一、模块一的核心目标

### 识别力是什么

识别力不是"知道自己有情绪"——每个人都知道自己有情绪。识别力是:

**在反应发生的过程中,能够看见"我正在被触发"——而不是完全陷在反应里,变成反应本身。**

这是一个精微的区分。

当你完全"是"愤怒时,你就是愤怒,没有空间,没有观察者。当你能说出"我现在正在生气"时,那个"说出"的部分就是识别力——它不在愤怒里面,它看着愤怒。

模块一要做的就是让这个"观察位置"变得越来越稳、越来越早、越来越细。

### 识别力的三个维度

识别力不是一个单一指标,有三个维度,都要练:

**维度一:识别的时机(从事后到当下到事前)**

- 事后几天才意识到"那天我被触发了"
- 事后几小时
- 事后几分钟
- 反应过程中
- 反应发生的瞬间
- 反应即将发生时的预警

**维度二:识别的颗粒度(从粗到细)**

- "我难受" → "我生气" → "我被冒犯了" → "我觉得自己不被看见" → "这是小时候不被爸妈看见的那种刺痛"

**维度三:识别的通道(认知 / 身体 / 情绪)**

- **认知通道:** 识别自己的念头、解读、叙事(他让我怎样 / 这不公平 / 我就是不够好)
- **身体通道:** 识别身体的触发信号(胸口紧、喉咙堵、胃揪、手心出汗)
- **情绪通道:** 识别情绪本身的名字和层次(不止"难受",而是"被看轻的那种羞耻")

三个通道都要练,因为反应模式会在不同通道优先激活,识别能力的瓶颈也会出现在不同通道。

### 为什么识别是第一步

不识别,所有其他工作都无从发生:

- 不识别,穿透无从开始(模块二)
- 不识别,新选择无从做出(模块三)
- 不识别,工具 A 和工具 B 都用不上(因为不知道该调用它们)

识别是反应模式工作的入口。模块一是 v3.0 训练路径的第一阶段。

## 二、模块一的训练构件

模块一有三个训练构件:**工具 C(主载体)+ 身体信号识别 + 情绪命名**。

三者的关系:

- 工具 C 是**纵向载体**——每天 / 每次触发时记录,累积材料
- 身体信号识别和情绪命名是**横向练习**——在任何触发发生时都可以做,增加识别的颗粒度

### 构件一:工具 C · 反应日志(核心载体)

详见《工具 C · 反应日志》独立文档。

模块一使用工具 C 时的重点:

- **训练起始:** 从工具 C 的最低起步版本开始(只答第 1 题 + 第 4 题)
- **训练过程:** 随着识别力增强,5 个问题里能答的越来越多,颗粒度越来越细
- **月度回看:** 是识别力训练的核心反馈机制——看自己这个月识别得更早了、更细了、更多了没

工具 C 在模块一中的特殊意义:**它让识别力这个看不见的能力,变成可追溯、可反馈的东西。** 没有工具 C,识别力的进步全靠感觉,感觉不可靠。

### 构件二:身体信号识别

#### 为什么要练身体信号

反应模式的触发**先在身体里发生,再到情绪,最后到念头**。大多数人只在念头层识别("我在生气"),但此时身体已经激活了好几分钟。

能识别身体信号,识别的时机就能往前提——在"生气"这个念头成型之前,就看到身体里的信号。这是识别力往事前推进的关键。

#### 路径 A:身体扫描式识别(强身体通道用户)

**日常练习(不限定触发时):**

每天一次,2 分钟。静下来,依次扫描:

- 胸口(紧 / 松 / 堵 / 空)
- 喉咙(紧 / 松 / 有东西 / 畅通)
- 胃(揪 / 松 / 翻 / 平静)
- 肩膀(耸 / 松)
- 下颌(咬紧 / 松)
- 手(攥 / 松 / 凉 / 暖)

不追求改变,只追求**能说出来自己身体各处的状态**。

**触发时练习:**

当你在日常里突然发现自己"情绪上来了",停 10 秒,扫描以上几个部位。记住状态。

积累一段时间后,你会发现:**每种反应模式都有自己的身体签名**。被否定触发时胸口会先紧;被忽视触发时喉咙会先堵。这些签名一旦熟悉,就能在下一次**通过身体信号预警触发**——身体说"这里要出问题了",你的识别前移到事前。

#### 路径 B:语言化身体识别(弱身体通道用户)

对心盲症 / 感觉钝化 / 严重述情障碍用户,身体扫描可能得到的都是"没什么特别的"——不是不配合,是信号本身微弱或接收不到。

对这类用户,**用语言做身体识别的替代**:

**日常练习:**

每天一次,写一句话回答:"此刻如果要用一个物理词形容我的身体状态,我会用什么?"

- "身体像一块冷木头"
- "有点紧,像被捏过的海绵慢慢回弹"
- "中空,像一个纸箱"
- "僵硬,像刚醒没活动开"

不追求"感觉到了什么",追求**用语言给身体状态命名**。语言本身就是识别——哪怕你感觉不到"紧",你写下"紧"这个字,也是把一个概念贴在了身体上。长期做,语言和身体的连接会慢慢建立。

**触发时练习:**

触发发生时,问自己:"如果我的身体在这一刻是一个画面 / 一个物品 / 一个颜色,它是什么?"不追求感觉,用联想回答。

路径 B 不是路径 A 的降级,是弱通道用户的主路径。做得久了,识别力同样扎实——只是走的是语言通道,不是感受通道。

### 构件三:情绪命名

#### 为什么要练情绪命名

情绪粒度(emotional granularity)是情绪研究里一个被广泛验证的指标:**能精细命名自己情绪的人,情绪调节能力更好,心理韧性更强**。

原因:当你只能说"我难受"时,你的大脑无法对这个模糊状态做任何针对性的工作。但当你能说"我感到被忽视的刺痛,混着一点不被重视的愤怒"时,每一个部分都可以被看见、被工作。

情绪命名练习就是练这个颗粒度。

#### 日常练习:每日情绪词

每天一次(建议晚上),问自己:"今天我有过什么情绪?"

**第一层答案(大多数人停在这里):**

- "还行""不错""挺累""烦"

**第二层答案(情绪粒度开始细化):**

- "中午那个会让我觉得被挑战""晚上和朋友聊天有点羡慕她""刚才刷到那条新闻有点无力感"

**第三层答案(情绪粒度更细):**

- "是那种被挑战之后的小刺——不是愤怒,更像是不服气加一点自我怀疑"
- "羡慕下面还有一层是'我怎么没在那个位置'的自责"
- "无力感底下是'我做什么都没用'的沉"

**练习方法:**

- 先写第一层,不强求
- 然后问"这个词背后更具体的是什么",写第二层
- 再问"这个感受下面还有什么",写第三层(如果能)

不要求每天都写到第三层。重点是**练习区分的习惯**——习惯了"还行"这个模糊词不够用,情绪粒度自然会细化。

#### 触发时练习:情绪的三个问题

触发发生时(或触发之后),问自己三个问题:

1. **我在感受什么?** (给出一个词)
2. **这个词下面还有什么?** (给出另一个词,可能是底层感受)
3. **这两个词加起来像什么熟悉的体验?** (可能指向过去某个场景的模式)

例:

- 第一个词:"生气"
- 下面是:"觉得自己被当工具使"
- 像什么:"小时候爸妈让我做事但从不问我意见那种感觉"

这一路走下来,识别就从"粗颗粒的生气"变成了**"被忽视个人意愿的老模式被激活"**——这是识别力深度的体现,也是模块二(穿透)的入口。

#### 情绪词汇的扩展(可选工具)

情绪粒度细化,需要词汇库。如果词汇不够,可以:

- 参考普鲁奇克情绪轮(Plutchik's Wheel of Emotions)
- 用 Gottman 的情绪词汇表
- 或者自己收集:每遇到一个精准描述你感受的词,记下来

这不是硬性要求。有些人天然词汇丰富,有些人需要积累。

## 三、训练路径(四个阶段 + 能力标志)

### 阶段一:识别的种子期

**典型状态:**

- 大多数时候不知道自己在反应模式里
- 偶尔事后几天或几周才想起"那天我是不是被触发了"
- 身体信号基本识别不到
- 情绪粒度停在"难受 / 烦 / 还行"

**核心训练:**

- 开始使用工具 C 最低版本(只答第 1 题 + 第 4 题)
- 身体信号识别做日常练习(路径 A 或 B)
- 情绪命名只做第一层
- 一周做 2-3 次记录就够

**进阶标志(不是时间,是能力):**

当你能**在事后几小时到一天内**识别出"我昨天 / 早上是被触发了",就进入了下一阶段。

### 阶段二:识别的萌芽期

**典型状态:**

- 事后几小时内能识别到触发
- 开始能感觉到一些身体信号,但不熟悉
- 情绪粒度开始到第二层

**核心训练:**

- 工具 C 尝试答 5 个问题里的 3-4 个
- 身体信号识别开始在触发时做(不只是日常)
- 情绪命名尝试第二层
- 一周记录 3-5 次

**进阶标志:**

当你能**在触发发生的当天或几分钟内**识别到"我正在被触发",就进入了下一阶段。

### 阶段三:识别的开花期

**典型状态:**

- 大部分触发在发生过程中就能识别
- 身体信号识别能预警一些触发
- 情绪粒度到第二层稳定,有时到第三层

**核心训练:**

- 工具 C 5 个问题全用,颗粒度更细
- 身体信号识别在日常里几乎自动
- 情绪命名触发时用三个问题练习
- 月度回看开始看得出 2-3 个月的趋势

**进阶标志:**

当你能**在触发之前就感知到身体信号并预警**("我感觉到这个对话要把我带进去了,但我还没完全被带进去"),就进入了下一阶段。

### 阶段四:识别的成熟期

**典型状态:**

- 触发的身体预警信号越来越熟悉
- 能在预警阶段就做出应对(不一定是新选择,但至少不完全被卷进去)
- 情绪粒度稳定细化
- 识别力本身变成了默认状态,不用刻意练

**核心训练:**

- 工具 C 变成"自然的日常反思",不是任务
- 身体信号和情绪命名都内化
- 月度回看成为持续的反馈

**这不是"完成"的标志,是下一阶段的起点。**

模块一的成熟意味着模块二(穿透)和模块三(选择)的工作可以深入——因为你有足够的识别基础去做这些工作了。

### 关于四个阶段的重要说明

**1. 时间不是关键。**

你可以在阶段一停留半年,也可以快速穿过。不重要。**关键是进阶标志——不是你练了多久,是你能做到什么**。

**2. 阶段之间不是单向的。**

压力大、身体不好、生活震荡时,你可能暂时退回到阶段一的状态。这很正常。识别力是神经系统层面的能力,会随状态波动,但练过的不会消失,状态好时会回来。

**3. 四个阶段不是四个完全不同的内容。**

都是同一套训练(工具 C + 身体识别 + 情绪命名),只是熟练度不同、颗粒度不同、使用频率不同。不要以为"进阶"了就要学新东西——还是这三个,只是越做越细、越做越自然。

## 四、模块一和其他模块的关系

### 模块一 → 模块二(穿透力)

模块一培养识别,模块二培养穿透——识别到被触发了,下一步是下潜到底层感受。

**顺序关系:识别是穿透的前提。** 没识别,不知道该穿透什么。所以模块一的训练至少要到阶段二(事后数小时能识别)才有资格开始系统做模块二。

**但这不是硬性门槛。** 工具 A 的第二段本身就在做急性期的穿透,这可以在模块一训练的任何阶段发生。模块二的系统训练需要识别力打底,但零散的穿透实践可以早期就开始。

### 模块一 → 模块三(选择力)

识别到 → 穿透了 → 才有资格做新的选择。模块一是选择力的基础。

### 模块一的循环(进阶后回到起点)

当你走到阶段四之后,你不会"毕业"——你会发现自己又回到阶段一,但看到的东西完全不同了:

- 以前识别不到的更微细的反应模式开始出现
- 身体信号里更精细的预警开始被看见
- 情绪粒度往第四层、第五层继续细化

**这是 v3.0 的循环结构:不是线性进阶到终点,是螺旋上升,同一个训练在不同深度反复做。**

## 五、防滑设计

### 防滑一:不让识别力变成新的自我评价

**信号:** "我又没识别到""我的识别力怎么还这么差""我该到阶段三了但还在阶段二"

**应对:** 识别这个念头本身——它是内在批评者在利用模块一打你。记一句:"今天我用识别力的标准打自己了。"这本身就是识别力训练。

### 防滑二:不追求"完美识别"

**信号:** 觉得"识别不到的部分就是失败"

**应对:** 识别力永远有盲区——因为识别的是我们神经系统的自动化反应,它的本性就是绕开我们的觉察。**识别一部分,盲掉一部分,是正常的**。进步是识别的部分在慢慢扩大,不是有一天所有盲区都消失。

### 防滑三:不把"识别"变成"立刻改变"

**信号:** "我识别到了,为什么我还是反应这么大""我看见了但我还是做不到"

**应对:** 模块一的目标是**识别**,不是改变。识别到了之后的工作是模块二和模块三的事。模块一只问"你看见了吗",不问"你改变了吗"。

### 防滑四:允许反复

**信号:** 某天 / 某周 / 某月识别力明显退步

**应对:** 识别力是神经系统能力,和睡眠、压力、身体健康、情绪状态都相关。状态不好时识别力会暂时退回到更低阶段——这不是退步,是状态波动。等状态恢复,识别力会回来。

### 防滑五:不在急性期评估识别力

**信号:** 在一场大反弹中觉得"我的识别力是不是归零了"

**应对:** 急性期本来就是识别力暂时下线的时期(前额叶掉线)。在急性期评估识别力像在地震中评估建筑稳定性——没有意义。等急性期过去,用工具 A 处理完,几天后再评估。

## 七、Agent 在模块一中的角色

Agent 不是模块一的主角,用户自己才是。Agent 的作用是:

**Agent 做的:**

- 用户需要时,帮助做工具 C 的月度回看(详见工具 C 文档)
- 用户卡住时,针对具体情境做点破 / 机制讲解(这是 agent 的核心价值)
- 用户问"我识别到了然后怎么办"时,指引到模块二(穿透)或工具 A(急性介入)
- 用户在防滑陷阱里时,及时拉回

**Agent 不做的:**

- 不替代用户做识别——识别是用户自己的能力,agent 不能代办
- 不给"你的识别力到哪个阶段了"的评分——阶段由用户自己判断,依据能力标志
- 不在每次对话都问"你今天做了模块一的练习没"——工具 C 不是打卡任务,模块一也不是

## 八、未来可能的扩展(v0.2+)

1. **按生存策略分支的识别重点** —— 不同生存策略的人识别重点不同。控制型识别"失控的瞬间",讨好型识别"不敢拒绝的瞬间",退缩型识别"想消失的瞬间",完美型识别"自我攻击的瞬间",受害者型识别"自我辩护的瞬间"。未来可以做分支指南
2. **按反弹主导类型分支的识别重点** —— 冲动上瘾型识别"用什么逃避",反应过度型识别"反应强度",习惯性反应型识别"自动化模式",过度期待型识别"预设",责怪受害型识别"归因"
3. **识别力的更细维度** —— 比如"识别自己的投射""识别自己的内在批评者的声音",这些是更高阶的识别工作
4. **和水老师一对一工作的集成**

以上是 v0.2+ 的事,v0.1 先跑起来。
