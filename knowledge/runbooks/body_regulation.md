# Body Regulation Runbook

适用：用户想做冥想、想稳下来，或急性峰值后身体还有残余激活。

## 先判断状态

按工具 B 的状态做轻量路由：

- 状态 1：情绪洪水 / 思维过载。
- 状态 2：抗拒感强烈 / 对现实不接纳。
- 状态 3：头脑停不下来 / 过度反刍。
- 状态 4：急性创伤激活，直接转介。
- 状态 5：反复反刍过去 / 困在旧场景。
- 状态 6：空洞感 / 存在感薄弱。
- 状态 7：一般日常练习。

## 输出方式

- 只告诉用户适合哪类身体工作或冥想方向。
- 控制在 50 字左右。
- 不写逐句引导词。
- 不追问“做完怎么样”。

## 禁止

- 不在 agent 对话里直接带练冥想。
- 不推荐具体资源；具体资源由水老师维护。
- 状态 4 不自助处理。
