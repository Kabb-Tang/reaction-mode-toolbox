# Inner Pattern Work Runbook

适用：用户明确想看内在模式。

## 流程

1. 先确认用户真正想看的问题。
2. 信息不足时问一个精准问题。
3. 信息足够时只说一个最关键观察。
4. 必要时调用话术库，但一轮最多一条。
5. 如果给练习指令，一次只给一条。

## 优先工具

优先级：

1. 精准提问
2. 反映用户原话
3. 一句话点破
4. 简短机制解释
5. 练习指令

## 禁止

- 不用单段输入做完整画像。
- 不贴“你是 X 型”。
- 不在用户健康自我反思时继续叠加诊断。
- 用户反弹后不换说法重复。

## 输出模板

```text
我先不急着下结论。

这里最关键的变量是：[变量]。
你说 [用户原话] 的时候，里面更像是 [两个可能方向]？还是都不是？
```
