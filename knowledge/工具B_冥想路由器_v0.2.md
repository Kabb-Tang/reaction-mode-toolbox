# 工具 B · 冥想路由器(v0.2)

> **定位:** 工具 A(急性止血脚本)之后的下一步。用户从急性峰值稳下来之后,根据当下状态,指向对应的身体工作 / 冥想类型。
>
> **设计原则:** 只出提示词,不出引导词。Agent 告诉用户"去做什么类型的冥想、用什么资源",不在 agent 对话中直接引导冥想过程。引导由专业资源(真人录音、冥想 app、线下课、治疗师)承担。
>
> **资源入口:** 所有具体资源(引导音频、冥想老师、身体工作治疗师、线下工作坊)统一由水老师提供和维护。Agent 做的是状态诊断和类型路由——告诉用户需要做哪一类冥想/身体工作;具体做哪个版本、用谁的引导、找谁做线下——联系水老师获取针对性推荐。这样水老师的专业筛选和学员的具体情况匹配可以持续优化,不固化在 agent 里。
>
> **版本状态:** v0.2。相对 v0.1 新增身体通道敏感度分支——专门为心盲症 / 感觉钝化 / 长期情感压抑的用户提供独立路径。

---

## 为什么需要工具 B

工具 A 解决"急性峰值里的止血"——五动作把用户从前额叶掉线状态拉回可操作状态。

但工具 A 之后,用户的底层感受(被触发的核心创伤、脆弱小孩、痛苦之身)**还在身体里**。如果只有工具 A,用户反复经历"触发→止血→日常→再触发→再止血"的循环,**感受没有被真正处理,只是被管住了**。

理论框架 框架里明确说过(4.1):创伤不只储存在头脑里,也储存在身体里、神经系统里。认知工作有价值但**无法直接重写神经系统**。要改变神经系统,需要身体层面的工作——感受、允许、释放、重新体验。

工具 B 就是指向这部分工作的路由器。

**关键定位:工具 B 不做身体工作,工具 B 指向身体工作。**

Agent 对话做不了真正的身体工作(详见"为什么不出引导词"部分)。但 agent 能做的是:识别用户当下最需要哪类身体工作,告诉他去哪里做。

---

## 为什么不出引导词

三个结构性原因:

**一、Agent 看不到用户实时状态。** 真正的冥想引导需要感应对方的呼吸、身体紧绷、情绪起伏——对着文字读引导词,节奏完全是用户自己凑的,引导的效果严重打折。

**二、引导词对措辞精度极其敏感。** 一句"现在你感到完全放松"对一个紧绷的人可能是**暗示性植入**(相反的指令)。专业冥想引导者经过训练,agent 没有。错误的引导词比没有引导词伤害更大。

**三、对特殊人群有真实风险。** 有解离倾向、未处理创伤、精神病理状态的用户,某些冥想(尤其是深度身体扫描、呼吸控制、观想类)可能**触发状态恶化**。Agent 无法筛查用户是否处于这类状态,独立引导是责任边界问题。

**所以工具 B 的产品形态是:告诉用户"去做",不假装自己能做。**

---

## 工具 B 的核心结构:七种状态 × 对应冥想

### 用户状态的诊断逻辑

Agent 在推荐工具 B 之前,先判断用户当下处于哪一类状态。诊断来自用户的表达(近期对话、工具 A 第三段的六题、情绪表达),不需要用户自己诊断——agent 观察并判断。

**状态诊断有一条重要前提:** 只在用户已经离开急性峰值后使用工具 B。急性峰值里不推荐任何需要"静下来感受"的冥想——那个状态下用户无法静下来。急性期用工具 A。工具 A 之后,或者非急性期的日常状态下,才是工具 B 的场景。

### 路由前的关键分支:身体通道敏感度

**在七种状态之前,agent 需要先判断一个维度——用户的身体通道敏感度。** 这个维度直接决定推荐哪一类冥想能真正起作用。

**为什么需要这一层分支:**

工具 B 的默认七种状态假设用户有一个可用的身体通道——能感受身体紧绷、能感知温度质地、能跟着身体扫描走。但有一部分用户**在身体通道层面是钝化的**:

- **心盲症(aphantasia)用户**:无法形成内部视觉意象。观想类冥想(包括"想象一道光""看见那个画面")完全失效。身体扫描如果带观想成分,也会失效
- **感觉钝化 / 长期情感压抑用户**:触觉、温度觉、内感受(interoception)迟钝。"你身体哪里紧"这类问题他们答不出来,不是不配合,是**信号本身微弱或接收不到**
- **发作性睡病 / 神经系统特殊性用户**:警觉度不稳定,某些冥想会触发状态切换(比如静坐触发困意)
- **严重述情障碍用户**:对情绪的粒度识别弱,传统"识别底层感受"的冥想思路难以进入

对这些用户,推荐默认路径(身体扫描、内在身体感知、感受性冥想)会有两个结果:

1. **用户做不下去**,挫败感反而累积,得出"冥想对我没用"的结论,关闭这条路径
2. **用户硬做**,用头脑伪装成"感受",变成另一种形式的理性化——外观在冥想,内在在分析

**识别身体通道敏感度的信号:**

**弱通道信号(指向路径 B):**

- 用户明确说过"我有心盲症""我感受不到身体""我对情绪比较钝"
- Agent 问"身体什么感觉"时用户反复答"没什么特别的""不太清楚""好像没感觉"
- 用户能清晰用语言描述情绪事件,但一问身体就卡住
- 用户自述以前做过冥想(身体扫描、呼吸觉察)效果差或坚持不下来
- 用户有明显的理性化倾向(语言密度高、概念清晰、身体描述为零)

**强通道信号(按默认路径 A):**

- 用户能自发描述身体感觉("胸口紧""喉咙堵""胃里有东西")
- 用户描述情绪时伴随身体位置词汇
- 用户有做身体工作的基础(瑜伽、武术、舞蹈、长期冥想等)

**混合信号或不确定时:**

- 不要贸然假设。先问一个精准问题:"你闭眼感受一下手的存在——你怎么知道你的手在那里?是通过看、通过感觉到重量/温度、还是通过想到'手在那里'这个想法?"——第三种答案指向弱通道
- 或者直接问:"你对身体的感受,平时是清楚的还是比较模糊的?"——用户自己的回答往往最准

**路径 A(默认身体通道路径)和路径 B(语言/认知通道路径)的关键原则:**

**路径 B 不是路径 A 的降级备选,是独立有效的路径。** 这一条必须明确——如果 agent 潜意识里把路径 A 当成"正路"、路径 B 当成"次优",会在话术里透露出来,让弱通道用户感到自己"少了一块"。事实是:他们没少,他们的主操作系统是语言,用语言路径做原本身体工作要做的事(深潜、识别底层感受、允许存在),在他们身上效率更高。

**下面的七种状态路由表同时提供路径 A 和路径 B。Agent 根据身体通道敏感度选择对应路径,不要交叉混用。**

### 七种状态 → 冥想类型对照

下面是核心路由表。每一种状态对应一个主推冥想类型 + 一到两个备选。

每个推荐控制在 50 字内——这是 agent 给用户的提示词长度硬限,强制保持在"提示"层不滑入"引导"。

---

**状态 1:情绪洪水 / 思维过载**

表现:用户说太多、反复说同一件事、句子里塞满情绪词、明显难以集中

对应需要:把注意力从头脑拉到身体,用身体作为锚

推荐冥想:**身体扫描冥想(Body Scan)**

Agent 提示词示例:
> "做一个身体扫描,20 分钟。从脚到头,每个部位停留几十秒,不分析,只感受。具体资源联系水老师获取推荐。"

**备选:内在身体感知**(更短,适合洪水刚退时)

Agent 提示词示例:
> "先闭眼 3 分钟。把注意力放到双手,不看不动,感受那个'在'的感觉。扩展到全身。"

理论框架 对应章节:**3.3 五扇门 · 门二(内在身体)** | **4.4 身体层面工作**

---

**状态 2:抗拒感强烈 / 对现实不接纳**

表现:反复说"我不接受""凭什么""这不公平",身体紧绷,对某个事实死活绕不过去

对应需要:从对抗位走到允许位,让抗拒本身被看见

推荐冥想:**臣服冥想 / 接纳练习**

Agent 提示词示例:
> "找一个安静空间,15 分钟。对着你抗拒的那件事,心里慢慢说:'就是这样了。'不加但是,不加我要改变。看身体有什么变化。"

理论框架 对应章节:**3.3 五扇门 · 门四(臣服)** | **4.9 接受** | **5.15 臣服**

---

**状态 3:头脑停不下来 / 过度反刍**

表现:反复分析、在同一个问题上打转、"道理我都懂但就是想"

对应需要:不是消除思维,是从思维内容转向思维之间的空隙

推荐冥想:**呼吸觉察(Anapana)/ 静默冥想**

Agent 提示词示例:
> "坐 20 分钟,只做一件事:注意呼吸进出鼻腔的感觉。念头来了看着它走,不跟。入门资源联系水老师获取推荐。"

**备选:静默觉察**(更高阶,适合有基础的用户)

Agent 提示词示例:
> "坐 15 分钟,把注意力放到声音之间的安静上。不是分析声音,是听'声音之间的空'。"

理论框架 对应章节:**3.3 五扇门 · 门三(停止思考)/ 门五(静默)**

---

**状态 4:急性创伤激活 / 身体强烈紧绷或颤抖**

表现:强烈躯体反应、说不清话、胸口堵、过度警觉、身体明显"锁住"

对应需要:不是静坐,是让身体完成它没完成的释放反应

推荐冥想:**此刻不推荐独立冥想,而是专业身体工作**

Agent 提示词示例:
> "这个状态不适合自己做冥想,会压不下来或者越做越激活。需要线下做 Somatic Experiencing(SE)或 TRE 等身体工作,具体治疗师联系水老师获取推荐。在此之前,做工具 A 的五动作保持稳定。"

**如果用户抗拒线下**,退到次优:

Agent 提示词示例:
> "次优选择:做 TRE 的入门练习,15 分钟,在安全私密的环境。身体出现颤抖是正常反应,让它发生。只做一次,看反应,再决定要不要继续。具体视频资源联系水老师获取推荐。"

理论框架 对应章节:**4.4 身体层面工作** | **4.7 神经源性颤抖**(如果 理论框架 有这一节,否则是 v3.0 需要补的)| **多层支持系统转介**

---

**状态 5:反复反刍过去 / 困在旧场景里**

表现:反复回想某个童年场景、某段关系、某次失败,像录像带在重播

对应需要:不是避开那个场景,是以一个成年的"在"回到那个场景

推荐冥想:**慈心冥想(Metta)/ 重新养育意象**

Agent 提示词示例:
> "做 20 分钟慈心冥想。重点不是对他人,是对你自己——尤其是你过去那个卡在场景里的那个小孩。具体引导资源联系水老师获取推荐。"

**备选:重新养育练习(非冥想)**

Agent 提示词示例:
> "不是冥想,是一个练习。对着那个场景里的小时候的自己,说三句话:'我看见你了。你当时做得够了。我现在在这里。'慢慢说,感受身体。"

理论框架 对应章节:**4.8 重新养育** | **5.5 母信念**

---

**状态 6:空洞感 / 存在感薄弱**

表现:"我不知道我要什么""我感觉空""我不确定我活着"——不是抑郁急性发作,是底色性的空

对应需要:不是填充这个空,是进入这个空,重新建立"在"的感觉

推荐冥想:**正念行走 / 身体存在练习**

Agent 提示词示例:
> "不坐,走。20 分钟。慢慢走,把注意力放在脚接触地面的感觉。不为了到哪,就是走和感受。最好在自然里。"

**备选:出厂设置冥想(框架独有)**

Agent 提示词示例:
> "坐 15 分钟。不做任何事。不呼吸觉察、不扫描、不观想。只是坐着,看你'不做任何事'时剩下的是什么。"

理论框架 对应章节:**3.1 临在** | **3.3 五扇门 · 门一(当下时刻)**

---

**状态 7:一般性日常练习 / 没有特定触发**

表现:用户问"日常我可以做什么冥想保养"——没有急性状态,只是想建立日常练习

对应需要:一个可持续的、低门槛的、建立基础的练习

推荐冥想:**每日 10 分钟呼吸觉察**

Agent 提示词示例:
> "每天一次,10 分钟,固定时间(推荐早晨)。只做呼吸觉察。不要求深度,只要求规律。具体引导资源或计时器推荐联系水老师。"

**进阶建议(一个月后):**

Agent 提示词示例:
> "基础稳了之后,加入每周一次 30-45 分钟的身体扫描,和偶尔一次慈心冥想。轮换,不固定。"

理论框架 对应章节:**3.10 觉察层的实用整合** | **临在基础练习**

## 路径 B:弱身体通道用户的七种状态对照

以下是针对身体通道敏感度弱的用户(心盲症、感觉钝化、严重述情障碍、发作性睡病等)的独立路径。和路径 A 的七种状态一一对应,但替换为以语言 / 认知 / 记忆 / 动作为核心通道的冥想类型。

**核心原则:绕过不可用的身体通道,用用户本来就强的通道做同样的工作。**

---

**状态 1(路径 B):情绪洪水 / 思维过载**

路径 A 推荐身体扫描——需要身体通道。对弱通道用户,换成**书写冥想 / 文字下潜**。

Agent 提示词示例:
> "现在不坐不扫描,写。打开一个空白文档,写 20 分钟,不编辑不审查,让语言自己跑。写完不看,关掉。具体方法联系水老师获取推荐。"

为什么有效:情绪洪水的本质是信息拥堵。对弱通道用户,堵的主要是语言思维——让语言流出来(不是被管理、不是被分析、只是流出来),洪水自然退。这在创伤治疗里对应"表达性写作"(Pennebaker 体系)。

**备选:念诵冥想(Mantra)**

Agent 提示词示例:
> "选一句简单的话(不是正面暗示,是中性锚点,比如'就这样'或一个单音节),重复念 15 分钟。念就好,不追求感受。具体方法联系水老师获取推荐。"

为什么有效:弱通道用户的头脑是主操作系统,给头脑一个简单重复的任务,它占满了就没法同时做反刍。这比"让头脑停下来"更可行——因为让它停下来是反直觉的,让它专注做一件简单的事是顺应它的。

理论框架 对应章节:**3.3 门三(停止思考的变体)**

---

**状态 2(路径 B):抗拒感强烈 / 对现实不接纳**

路径 A 推荐臣服冥想——需要身体感受抗拒的松紧。对弱通道用户,换成**口述臣服 / 接纳宣言**。

Agent 提示词示例:
> "找一个安静空间,15 分钟。对着你抗拒的那件事,出声慢慢说:'就是这样了。'一次一次重复。不加但是。不追求感受变化,追求的是这句话本身被你说出来。"

为什么有效:弱通道用户无法通过"感受身体松紧"验证臣服——但他们能通过"这句话说出来时有什么卡住""说到第几次开始顺畅"来验证。语言的卡顿本身就是抗拒的表达,语言的顺畅本身就是接纳的到来。

**备选:书写对话法**

Agent 提示词示例:
> "用左手(非惯用手)写下你抗拒的那个声音在说什么,然后用右手回应。左手右手交替,写 20 分钟。不思考,直写。"

理论框架 对应章节:**3.3 门四(臣服的语言通道变体)** | **4.9 接受**

---

**状态 3(路径 B):头脑停不下来 / 过度反刍**

路径 A 推荐呼吸觉察——对部分弱通道用户仍有效,但对纯语言型用户效率不高。换成**数息冥想(纯计数)**。

Agent 提示词示例:
> "坐 20 分钟,数呼吸。吸 1,呼 2,吸 3,呼 4,到 10 重来。不关注呼吸的感受,只关注数字本身。断了就从 1 开始。"

为什么有效:纯语言型头脑需要一个占用语言处理器的任务,而不是一个要求放空语言的任务。数字是最简单的语言占用,能用头脑本身压住头脑的反刍。

**备选:慢读冥想**

Agent 提示词示例:
> "选一段不熟悉的诗或短文,20 分钟内缓慢读完,每个字之间停一秒。不追求理解,只追求把每个字读出声。"

理论框架 对应章节:**3.3 门三(停止思考的变体)**

---

**状态 4(路径 B):急性创伤激活 / 身体强烈紧绷**

**路径 A 和路径 B 在这一状态下合并——都不自助,都转介水老师线下。** 急性创伤激活是跨通道的硬边界,弱通道用户在这个状态下更不应该自助。

Agent 提示词示例(和路径 A 一致):
> "这个状态不适合自己做冥想,会压不下来或者越做越激活。需要线下做 Somatic Experiencing(SE)或 TRE 等身体工作,具体治疗师联系水老师获取推荐。在此之前,做工具 A 的五动作保持稳定。"

**特别说明:** 对弱通道用户,线下身体工作治疗师的重要性比强通道用户更高——因为他们无法通过自己的身体信号判断自己是否正在恶化,必须有专业人员在场观察。这一条推荐时 agent 可以强调。

理论框架 对应章节:**4.4 身体层面工作** | **多层支持系统转介**

---

**状态 5(路径 B):反复反刍过去 / 困在旧场景**

路径 A 推荐慈心冥想 / 重新养育意象——"意象"对心盲症用户直接失效。换成**口述重新养育 / 写信给内在小孩**。

Agent 提示词示例:
> "不做冥想,做一个练习。对着过去某个场景里的自己(不用观想画面,就在心里确认是谁),大声说三句话:'我看见你了。你当时做得够了。我现在在这里。'慢慢说,重复到不需要再说。"

为什么有效:重新养育的核心是"让小时候的自己被成年的自己接住"——这个接住的动作,可以通过意象(强通道)完成,也可以通过语言承诺(弱通道)完成。两者效果等价,媒介不同。

**备选:写信冥想**

Agent 提示词示例:
> "给过去某段时间的自己写一封信,不限字数,不修改。写完不寄出,放 24 小时,再决定要不要读。"

理论框架对应章节:**4.8 重新养育(语言通道变体)** | **5.5 母信念**

---

**状态 6(路径 B):空洞感 / 存在感薄弱**

路径 A 推荐正念行走 / 身体存在练习——对发作性睡病、感觉钝化用户不一定有效(行走时困意可能加重,或感觉"走了还是空")。换成**命名冥想 / 存在确认**。

Agent 提示词示例:
> "坐 15 分钟。每 30 秒出声说一次当下的事实:'我在这里。今天是 X 年 X 月 X 日。我叫 X。我正在坐着。'不追求感受,只追求说这些句子。"

为什么有效:空洞感对语言型用户来说,核心是"存在感"的语言锚定丢失了。通过反复用语言确认自己的存在,比试图"感觉到存在"更直接。这在创伤学里对应"grounding technique"(着陆技术)的变体。

**备选:对话记录法**

Agent 提示词示例:
> "和一个人(可以是朋友、可以是水老师、实在没有就写给未来的自己)进行一次 20 分钟的结构化对话,对方问你'你今天做了什么''你现在想什么''你在乎什么',你回答。不追求深度,追求'被确认存在'。"

理论框架 对应章节:**3.1 临在(语言通道变体)** | **3.3 门一**

---

**状态 7(路径 B):一般性日常练习**

路径 A 推荐每日呼吸觉察——对弱通道用户可换成**日记冥想**。

Agent 提示词示例:
> "每天一次,10 分钟,固定时间。写日记——不是复盘不是规划,是'此刻我在想什么'的实时捕捉。写完不读不发。具体引导资源联系水老师。"

为什么有效:对语言型用户,日记是最自然的日常冥想——不需要对抗自己的主通道,直接用主通道做自我观察。坚持率比呼吸觉察高很多。

**进阶建议(一个月后):**

Agent 提示词示例:
> "基础稳了之后,加入每周一次 30-45 分钟的书写冥想(状态 1 的那种无编辑书写)和偶尔一次写信冥想(状态 5 的那种)。轮换,不固定。"

理论框架 对应章节:**3.10 觉察层的实用整合** | **临在基础练习(语言通道变体)**

## 路径 A 和路径 B 的综合使用原则

**1. 一个用户在不同时刻可以使用不同路径。**

身体通道敏感度不是完全固定的。同一个用户,在放松状态下通道可能强一些,在压力或嗜睡发作时可能变弱。Agent 每次推荐前快速判断当下的通道状态,再决定用路径 A 还是路径 B。

**2. 强通道用户也可以尝试路径 B,反之则谨慎。**

强身体通道用户做路径 B 的冥想(书写、数息、口述臣服等)没有副作用,反而能多一个工具。但弱身体通道用户强做路径 A 的冥想(身体扫描、内在身体感知)可能累积挫败感——这个方向的跨界要谨慎,需要明确是"探索",不是"我应该能做到"。

**3. 混合路径是可能的,但要明确结构。**

比如一个中等通道用户,可以做路径 A 的身体扫描(主),同时辅以路径 B 的书写冥想(辅)。关键是**每一次练习内部只走一条路径,不在一次练习中混用**。一次 20 分钟的身体扫描里不要突然切换到"对了你写一下日记"——这会打断两条路径的各自深度。

**4. 弱通道用户不是残障,是不同配置。**

这一条值得 agent 反复内化。路径 B 的存在不是"给做不到路径 A 的人的备选",是"给另一种认知系统的主路径"。在话术和推荐语气上,要让弱通道用户感到**这就是为你设计的**,而不是**我们为你找了一个替代品**。

**5. 路径 B 的长期价值可能不止于"弱通道用户的主路径"。**

对任何用户,在嗜睡、过度疲劳、身体通道暂时掉线的状态下,路径 B 都是可用的备选。Agent 可以告诉强通道用户:"你的主路径是 A,但疲劳的时候可以用 B 维持练习,不要因为做不了 A 就完全停掉。"

## Agent 如何使用工具 B

### 触发时机

**优先触发:** 用户做完工具 A 第二段、下潜到底层感受之后。工具 A 让他看见了,工具 B 告诉他下一步去做什么身体工作处理它。

**日常触发:** 用户在非急性期问"我平时可以做什么练习"——用状态 7。

**特定状态触发:** Agent 在对话中识别到用户处于状态 1-6 之一,且不是急性峰值——可以推荐对应冥想类型。

### 不触发的情况

- **急性峰值中:** 用工具 A 不用工具 B
- **用户不想做:** 不推。工具 B 是提供选项,不是任务
- **用户已经有稳定的冥想习惯:** 不覆盖他的习惯,除非他当前状态和他的习惯不匹配
- **用户处于状态 4(急性创伤激活):** 不自助推冥想,直接推专业转介

### 推荐的话术结构

**不要说:** "我推荐你做 X 冥想" —— 太销售化,用户会觉得 agent 在"开药"

**可以说:** "你现在这个状态(简要描述),对应的工作不是继续在头脑里分析,是身体层的 X。[50 字内的提示词]。做完再回来聊。"

**关键:** 说清楚"为什么是这类冥想"(挂回状态诊断),而不是只给推荐。用户需要理解"这个状态 → 这类冥想"的映射,下次他自己能用。

### 不要做的事

1. **不要在 agent 对话中自己写引导词。** 底线是 50 字提示。超过就违反工具 B 的设计
2. **不要推荐多个选项让用户选。** 一次一个主推。备选只在主推不适合时提
3. **不要追问"做完怎么样"。** 用户做完如果想聊,他会回来。追问会让冥想变成"向 agent 交作业"
4. **不要和工具 A 同时推。** 工具 A 在急性期,工具 B 在急性期之后。两个一起推会把用户搞乱
5. **不要替代专业资源。** 推荐完就停。不要再补"其实你也可以和我聊聊"之类的话——那是把用户从身体工作拉回对话,违反工具 B 的定位

## 工具 B 的边界:它不能做什么

**工具 B 不是治疗。** 它是"知道下一步去做什么"的路由器。真正的改变发生在身体工作里,不发生在 agent 告诉用户去做什么的那一刻。

**工具 B 不保证冥想适合用户。** 推荐的冥想类型是通用的最佳匹配,但个体差异极大。有些人对身体扫描反应好,有些人反应差。用户做了一次发现不对劲,应该停,换一种,或者找专业人员。Agent 不为冥想效果背书。

**工具 B 不处理精神病理状态。** 工具 B 假设用户的状态在"一般心理困扰"到"有基础的自我工作者"这个范围内。超出这个范围(精神分裂谱系、严重双相、未处理的急性 PTSD、活动期重度抑郁)——工具 B 不适用,应该转介精神科 / 创伤治疗师,不是推荐冥想。

**工具 B 不替代线下身体工作。** 对严重创伤、长期躯体化、深度解离——独立冥想有限,需要身体在场的专业支持。工具 B 会在状态 4 明确指出这一点。

---

## 与工具 A 的衔接逻辑

工具 A 和工具 B 是**序列关系**,不是并列关系:

```
急性触发 → 工具 A 第一段(止血,60-180秒)
         → 工具 A 第二段(深潜接受,30分钟+)
         → 工具 A 第三段(复盘,可选)
             ↓
         [用户下潜到底层感受、或处理完急性期]
             ↓
         工具 B(根据当下状态指向身体工作)
             ↓
         [用户完成身体工作,带体验回来]
             ↓
         Agent 对话(母信念/重新养育/溯源的深度工作)
```

整个架构的本质是:

- **工具 A**:用户独立执行的急性期动作脚本
- **工具 B**:用户独立执行的后续身体工作路由
- **Agent 对话**:前后两端的理论层 / 看见层工作

Agent 不在中间做冥想或身体工作,agent 做两端的"看见"和"整合"。

## 未来可能的扩展

v0.2 留白、后续可加的方向:

1. **按生存策略分支的推荐**——控制型用户、讨好型用户、退缩型用户对冥想的反应不同。未来可以按 理论框架 的生存策略做二级分支
2. **按具体触发类型的更细分路由**——比如被抛弃触发、被吞没触发、羞耻触发对应的冥想类型可能有细微差异
3. **资源库的扩展和维护**——目前所有推荐都指向水老师获取具体资源。水老师可以按冥想类型、适用状态、路径 A/B、中英文、收费/免费、线上/线下等维度建立资源索引,按学员情况动态推荐。这也是 agent 之外水老师的专业价值所在
4. **治疗师 / 工作坊的转介网络**——状态 4 和身体工作建议需要明确的线下资源。水老师的转介网络本身是 agent 无法替代的专业资产
5. **路径 B 的持续扩展**——v0.2 的路径 B 基于对弱通道用户的当前理解。实际使用中会暴露出哪些状态的路径 B 工具最有效、哪些需要继续开发。需要通过实际反馈迭代
6. **第三通道的可能性**——目前只区分身体通道(路径 A)和语言通道(路径 B)。可能还有第三种用户主要依赖动作通道(武术、舞蹈、运动),对这类用户某些动态冥想(气功、太极、5rhythms)可能是主路径。v0.2 尚未覆盖,留给后续

以上都是 v0.3+ 的事,v0.2 先跑起来。
