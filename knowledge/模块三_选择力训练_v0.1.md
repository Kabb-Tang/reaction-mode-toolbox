# 模块三 · 选择力训练(v0.1 初稿)

> **定位:** v3.0 反应模式工作坊三大训练模块之一。在识别和穿透接受到位之后,练习识别"涌现的回应"和"旧模式的回应"的区别,并培养跟随涌现的勇气。
>
> **核心轴:** 减少反应模式(选择力不是"做新选择的能力",是"识别 + 跟随"——避开"必须做新选择"这个新的反应模式陷阱)。
>
> **版本状态:** v0.1 初稿。模块三是 v3.0 三大模块里"最大空白,从零建设"的一轮——没有现成构件可整合,核心载体共用工具 C 的扩展用法。待使用反馈再迭代。

---

## 一、模块三的核心目标

### 选择力不是"做新选择的能力"

这是模块三最容易被误解的地方,所以放在最前面说。

**选择力 ≠ "我必须做不同于旧模式的选择"。**

如果把选择力定义成"做新选择的能力","必须做新选择"立刻就变成新的反应模式——你被"应该不一样"推着走,这和被"应该讨好""应该控制"推着走没有本质区别,只是反应模式换了一件衣服。

**真正的选择力是两个能力组成的:**

1. **识别一个回应是从旧模式来,还是从底层涌现** —— 穿透接受到位之后,在你身上同时出现的两种(或多种)候选回应。能区分它们,是模块三的第一项工作
2. **当涌现的回应出现时,有勇气跟随它** —— 跟随往往违反舒适区(所以叫"冒险"),但这个跟随不是"我必须不一样"的强迫,是"我看见了底层来的那个,我不再走旧路"的自由

这两个能力合起来,模块三的工作是:**让选择浮现,跟随真实的那个**。不是制造新选择,是在选择浮现时不再自动走老路。

这个区分是模块三的灵魂。后面所有训练设计都建立在这个区分上。

### 减少反应模式悖论的显性处理

v3.0 的核心轴是"减少反应模式"——但**把"减少反应模式"本身当目标,会让"减少反应模式"成为新的反应模式驱动力**。

模块三是这个悖论最尖锐的地方。在模块一(识别)里,识别本身没有"必须"的味道——你识别得到就识别,识别不到就识别不到。在模块二(穿透接受)里,接受的姿态本身就排除"必须"——一旦"必须接受"出现,接受立刻不成立。

但模块三里——"做新选择"特别容易被扭曲成"必须做新选择"。

**这个悖论的解药就在选择力的定义里:**

- 不练"做新选择",练"识别 + 跟随"
- 不练"必须不一样",练"看见旧的那个不必走"
- 不练"勇气",练"在反复看见里发现旧路真的不是唯一的"

**实操层的检验:** 当你想做某件"新选择"时,问自己——这个"想做"的质感是紧的(被推)还是松的(被涌)?如果是紧的,那不是选择力,是新形式的反应模式。停下来。

模块三全程都在围绕这个悖论运作。后面的防滑设计有专门一条处理,但**整个架构的根基已经在定义里把悖论解构了**。

### 选择力的三个维度

类比识别力和穿透力的三维结构,选择力也有三个维度:

**维度一:候选的辨识(看到选择存在)**

- 反应自动发生,完全没看到任何"我有选择"
- 事后才意识到当时其实可以不那样
- 当下看到了候选,但已经选了
- 当下看到了候选,能停一下
- 候选浮现成为常态——做事时自然知道"还有别的可能"

**维度二:质感的识别(能区分旧 vs 新)**

- "都差不多""不知道哪个是旧哪个是新"
- 事后能看出哪个是旧模式
- 当下能感觉到两个候选的质感不同——旧模式紧、推、应该;涌现的回应松、涌、想
- 在质感差别的基础上做下一步
- 质感识别成为默认能力

**维度三:跟随的勇气(敢跟随涌现的回应)**

- 看到了涌现的回应,但旧模式的拉力太强,跟不上
- 偶尔跟随,事后被旧模式反扑(后悔、自责、缩回去)
- 跟随之后能稳住(结果不一定好,但不撤回这个选择)
- 大部分时候能跟随,大场面或高风险时还会缩
- 跟随成为本能——不需要刻意"鼓起勇气"

注意:**勇气不是"故意鼓起来"的**。勇气是"反复看见旧路不必走 + 偶尔跟随发现没塌"累积出来的副产品。模块三不直接训练勇气(理由在第二部分构件设计里展开)。

### 为什么选择是第三步

识别让你看见反应;穿透接受让感受流动;但**反应模式是否真正减少,看的是下一次触发时,你走的是旧路还是新路**。

- 光识别不改路,反应模式只是被识别地循环
- 光穿透接受不改路,反应模式只是底层被处理但行为依然旧

**反应模式真正减少的标志,是行为模式开始变。**

但这个"变"不是"必须变"——如果用强迫"必须做新的"来改路,改的是表面,反应模式的根还在(只是穿了"我要新"的外衣)。

模块三的工作是让"改路"自然发生:基于真实的辨识 + 基于松的跟随。这才是 内在转化理论框架 5.3 冒险的本意——**带着觉知做不同的选择**,觉知而不是强迫,选择而不是必须。

模块三是 v3.0 训练路径的第三阶段。识别是入口,穿透接受是工作,选择力是工作的兑现。

## 二、模块三的训练构件

模块三有三个训练构件:**核心载体(工具 C 的选择层扩展)+ 候选观察练习(横向)+ 质感识别练习(横向)**。

注意:**没有第四个"勇气跟随训练"构件**。这是设计选择,不是疏漏。理由在本节末尾详述。

### 构件一:核心载体——工具 C 的选择层扩展

模块三不新建工具。当用户进入模块三阶段(模块二到位之后),工具 C 的用法扩展,加入选择层的开放问题。

#### 为什么不新建工具

模块三最大的陷阱是制造新的反应模式驱动力。一个新的"选择日志"几乎一定会变成"打卡新选择"——用户开始为了填表而找新选择,新选择变成任务。这直接撞上悖论。

工具 C 已经是开放式日记,加入选择层问题不破坏其形态——用户在工具 C 写到反应时,自然延伸到"那次有没有别的可能"这一层。这种延伸是有机的,不是新工具。

#### 扩展的内容(待和工具 C 对照定稿)

工具 C 现有 5 题。模块三阶段可加入 1-2 题(具体题号和措辞在 v0.2 整合时和工具 C 维护者对照)。建议方向:

- "今天有没有一刻,我感觉到不止一个回应在我身上?"(维度一:候选辨识)
- "那一刻,这两个回应的质感分别是什么?哪个紧,哪个松?"(维度二:质感识别)
- (可选,不强制)"我跟随了哪个?"(不评判选了什么,只是观察)

#### 关键设计原则

- **不要求每次都答** —— 工具 C 是开放日记,模块三的题不强制
- **不评判答案** —— "我跟随了旧的"和"我跟随了新的"在工具 C 里没有高低,只有记录
- **不要求"做对"** —— 模块三阶段记录的核心不是"这次我选对了",是"我看到了选择存在"

#### 月度回看的视角

每月看一次工具 C 的记录,问自己:

- 这个月我看到"有候选"的次数,比上个月多了吗?
- 我能感觉到质感差别的频率,有没有提高?
- 我跟随涌现的次数,变了多少?(不是越多越好,是观察趋势)

模块一回看的是识别得更早/更细;模块二回看的是穿透得更深/更稳;**模块三回看的是看见选择的频率和跟随的稳定度**。

### 构件二:候选观察练习(日常横向)

#### 为什么要练候选观察

很多人在反应发生时,完全感觉不到"我有选择"。**反应是自动发生的,候选根本没浮现到意识层**。

候选观察练习是练**让候选浮上来**的能力。在低风险的日常小事里练习多停一秒,看是否有不止一个候选。这是把"看见选择本身"内化成日常意识。

注意:这个练习**不要求选对**,只要求看见。

#### 路径 A 和 路径 B(共用)

候选观察主要是认知-内省层面,身体通道差异不大。两条路径用同一种练习方式。

#### 日常练习

每天选一个低风险的小决策,练习多停一秒:

- "现在我要喝水,还是不喝?"
- "这条消息我现在回,还是等等?"
- "走楼梯还是电梯?"
- "对这个邀请说好,还是说不?"

不需要在重要决策上做这个练习,日常的就够了。具体做法:

1. 注意到自己即将自动做出一个回应
2. 停一秒(只是一秒,不是十分钟)
3. 问自己一句:"这件事我有几种可能?"
4. 看候选浮上来——可能两个、可能三个、可能五个
5. 然后选一个就行(选哪个不重要,看见有候选才重要)

**做这个练习不要求"选最好的"**——选哪个都行。重点是看见"我可以选"这件事在意识里成立。

**最难的地方:** 大部分小决策你根本没意识到是个决策。比如"早上起床后第一件事"——很多人完全是自动的:摸手机、上厕所、刷牙——没有任何"选择"的体验。**这个练习就是让这些自动行为显出"选择"的形状**,哪怕选完还是同一件事,看见它是选择就有用。

#### 进阶:在反应模式上做候选观察

熟悉了在小决策上的练习后,可以扩展到反应模式上。

下次你被触发时(在工具 A 第二段的"动作五:报时"之后,有了一点稳的状态后),问自己:

- "现在我最想做的反应是什么?"
- "如果我不做这个反应,我会做什么?"
- "如果我也不做这个,会做什么?"

不要求做出新选择,只要求**让 2-3 个候选浮上来**。然后该做什么做什么。

这个进阶版本要在模块二到位之后做——还没穿透接受时做这个,容易变成"我必须找到新选择"的逼迫。

### 构件三:质感识别练习(日常横向)

#### 为什么要练质感识别

候选浮上来之后,问题来了——**怎么知道哪个是从旧模式来,哪个是从底层涌现的?**

答案是"质感"——它们感觉不一样。但大部分人没练过这种区分,候选浮上来也分不清。

质感识别练习就是练这个区分能力。

#### 旧模式 vs 涌现回应 的典型质感对比

(这是练习的参考,不是评分标准)

| 旧模式回应 | 涌现回应 |
|---|---|
| 紧 | 松 |
| 推(被推着) | 涌(自己升起) |
| 应该 / 必须 | 想 / 愿意 |
| 急促 / 立刻要做 | 不急 / 可以等一下 |
| 害怕不做的后果 | 不害怕,只是这是下一步 |
| 内在有"声音"在说怎么做 | 内在没声音,就是知道 |
| 做完后疲惫 | 做完后平静 |

**重要:这是参考,不是教条。** 有些情况下涌现的回应也带紧(比如真正需要紧急行动时),有些情况下旧模式回应也表面松(比如根深蒂固的讨好已经感觉不到推)。**质感识别是培养感觉,不是套表格**。

#### 路径 A:身体质感识别(强身体通道)

**日常练习:** 

针对今天的某一个反应(不必触发级,日常的就行),事后问:

- 当时这个反应,是从身体哪里来的?(胸口的紧?喉咙的堵?胃的揪?头的发热?)
- 它的质感是什么?(用 2-3 个词描述)
- 现在回看,如果当时另有一个候选,它会是什么质感?

练这个,慢慢会熟悉旧模式回应在你身上的"指纹"——它从哪里来、是什么质感。当下次它升起时,你会更早识别。

#### 路径 B:语言质感识别(弱身体通道)

身体质感对心盲症 / 感觉钝化 / 严重述情障碍用户难直接感受,**用语言描述代替**。

**日常练习:**

针对今天的某一个反应,事后写下:

- 当时我的反应是: ___
- 在做这个反应之前,我有没有"应该"这个词在心里?(或类似:必须、得、不然就、否则)
- 这个反应给我的内在感觉,如果用一个词形容,是什么?(紧?推?急?压?或:松?涌?自然?平?)
- 如果当时有另一个候选,它会带"应该"这个词吗?

**关键诊断词:"应该"。** 旧模式回应几乎一定带某种"应该"(显性或隐性);涌现回应的核心特征是**没有应该**——它就是下一步,不需要论证。

弱身体通道用户用"应该的有无"作为质感的语言代理,在结构上等价于强通道用户用身体紧/松作为质感识别。

#### 关于臣服作为涌现回应的特殊形态

内在转化理论框架 5.15 区分了三种"不抗争"——妥协、接纳、臣服。在模块三里,**臣服可以是涌现回应的一种形态**——当下的涌现是"不行动,允许它如其所是"。

但这里有一个最容易混淆的点:**臣服和逃避都看起来是"不行动"**。

区分方法和质感识别一致:

- **臣服的质感:** 松、平、不抗;身体不紧
- **逃避的质感:** 紧、缩、推开;身体有压

同样用"应该"的诊断:

- 臣服没有应该——就是这样了,接受了
- 逃避有"应该不面对""不能承受"的隐性应该

详见防滑六。这点在模块三里重要,因为越练选择力越容易遇到"我跟随的'臣服'其实是逃避"的混淆。

### 为什么没有第四个"勇气跟随"构件

这是模块三最关键的设计选择。

**勇气不是被独立训练出来的能力。** 勇气是在以下循环里**累积**出来的副产品:

```
看见候选(候选观察练习)
   ↓
分辨质感(质感识别练习)
   ↓
偶尔跟随涌现的那个
   ↓
发现"跟随了之后没塌"(就是这个发现,慢慢累积成勇气)
   ↓
下次更容易跟随
```

如果给"勇气"一个独立的训练设计——比如"每天做一件让你害怕的事"——这立刻撞上悖论。"必须勇敢"变成新的反应模式驱动力,用户被"应该有勇气"推着走,做出来的不是真跟随,是另一种形式的强迫。

所以模块三**不直接训练勇气**。模块三训练的是能让勇气自然累积的两个能力(候选辨识 + 质感识别)。剩下的事——"偶尔跟随" + "发现没塌"——交给生活本身,不交给训练设计。

但需要在 agent 角色和阶段标志里把这一层显性化,确保"跟随"不被忽略。

## 三、训练路径(四个阶段 + 能力标志)

模块三的进阶标志由三个维度构成:**候选辨识 + 质感识别 + 跟随勇气**。和模块一二的设计一致——能力标志,不是时间。

### 阶段一:候选盲

**典型状态:**

- 反应自动发生,完全没看到"我有选择"
- 事后回看才偶尔意识到"当时其实可以不那样"
- 候选观察练习刚开始,经常忘记停那一秒
- 被问到"这次反应的质感"答不上来——"就是这样啊,有什么质感"

**核心训练:**

- 工具 C 的选择层扩展题先不用,继续按模块二的用法记录
- 候选观察练习每天做(在低风险小决策上)
- 质感识别练习每周做 1-2 次(针对最近一个反应)
- 不要求跟随涌现的回应——这个阶段连涌现是什么都还没体验

**进阶标志:**

当你**事后能清晰回看出"那次反应是旧模式,当时有别的可能"**——能在脑子里描述出那个没走的候选——就进入了下一阶段。

注意:这一阶段最长。候选盲是大部分人长期的状态。**不要求快速突破**——慢就是模块三的常态。

### 阶段二:候选可见

**典型状态:**

- 当下能看到不止一个候选(虽然往往已经选了旧的)
- 事后能描述出 2-3 个候选,知道哪个是旧模式
- 偶尔能感觉到候选间的质感差别
- 跟随涌现回应的次数还很少,但开始出现

**核心训练:**

- 工具 C 选择层扩展题开始用——记录"今天看到选择存在"的那些时刻
- 候选观察练习扩展到反应模式上(在工具 A 第二段之后做)
- 质感识别练习日常化
- 当涌现回应出现且情境允许时,**可以**跟随,但不强求

**进阶标志:**

当你能**在当下感觉到候选间的质感差别**(不只是事后),并且**至少有几次跟随了涌现的回应,事后没有撤回那个选择**(无论结果如何)——就进入了下一阶段。

注意"没撤回"的意思:不是结果一定好,是**你做完那个选择之后,没有用旧模式回去补救**。比如你第一次说"不",对方不高兴,你没有立刻补一句"算了我可以"——这就是没撤回。

### 阶段三:质感分辨

**典型状态:**

- 大部分反应当下能感觉到候选的质感差别
- 跟随涌现的回应变得稳定(中等场合能做到)
- 大场面或高风险下还会缩回旧模式,但能事后看见
- 开始出现"我做了不同的选择,世界没塌"的具身体验

**核心训练:**

- 工具 C 选择层扩展题成为常用记录
- 候选观察和质感识别变成日常意识(不需要刻意练)
- 开始遇到"臣服 vs 逃避"的混淆——需要更细的质感识别

**进阶标志:**

当你**在中等强度触发的当下,能跟随涌现的回应,而不被旧模式拉回**——并且**事后回看,能确认那次跟随是松的(不是逼自己"必须不一样")**——就进入了下一阶段。

### 阶段四:自由涌现

**典型状态:**

- 反应模式发作的频率明显降低(不是消失,是减少)
- 当涌现的回应升起时,跟随它是自然的——不需要刻意"鼓起勇气"
- 旧模式被识别得越来越早,有时根本没发作就被代替
- 候选辨识和质感识别变成默认能力,不再是"练习"

**核心训练:**

- 不再有"模块三训练"的边界感——它就是生活的一部分
- 工具 C 偶尔记录,不强制
- 大场面或全新的领域里,可能还会回到阶段二三的状态——这是正常的,不是退步

**这不是终点。**

模块三的成熟意味着 v3.0 三大模块的训练路径走完一遍。但这不是"反应模式被消除"——内在转化理论框架 3.8 明确说过反应是正常的,模块的目标是减少而不是消除。

走到这里之后,会发现:

- 更深层的反应模式开始浮现(以前没看见的)
- 候选辨识和质感识别要在新的、更微妙的领域重新建立
- 同一个核心反应模式,可能要在不同情境下反复经历"识别 → 穿透 → 选择"的全套循环

**这是 v3.0 的循环结构——三大模块都共用。**

### 关于四个阶段的重要说明

**1. 时间真的不是关键。** 模块三的阶段一可能持续几个月到几年。这不是失败。

**2. 阶段之间会反复,而且模块三反复得最厉害。** 你可能在亲密关系上到了阶段三,在工作上还在阶段一,在面对父母时回到候选盲。这是正常的——选择力高度情境化。

**3. 阶段四不意味着"我永远做对的选择"。** 永远做对的选择是另一种反应模式(完美主义版)。阶段四的标志是"跟随是松的",不是"选择是对的"。

**4. 不要用结果评判。** 跟随涌现回应,结果可能不好——内在转化理论框架 5.3 明确说过冒险的真正价值不在结果。你说了真话对方走了,你设了界关系变了——这些不是"模块三没练好"的证据,这是冒险的本意。

## 四、模块三和其他模块的关系

### 模块三 ← 模块一(识别力)

候选辨识本质上是识别力的进阶应用——识别"反应模式正在发生"是模块一的工作,识别"现在有几个候选 + 哪个是旧的"是模块三的工作。同一种能力(识别),在不同对象上(模式 vs 候选)。

这意味着:**模块三的训练要求模块一至少到阶段三**(开花期,大部分触发能在过程中识别)。识别力还在阶段一二时,候选根本浮不上来——你连反应自身都还没看清楚,更看不清候选。

### 模块三 ← 模块二(穿透接受)

涌现的回应从哪里来?**从穿透接受到的底层来。**

这是 内在转化理论框架 4.9 的核心洞察:真正的转化发生在接受里,选择只是接受之后的自然涌现。如果没有穿透接受,候选浮上来的都是"反应模式的不同变体"——不会有真正的涌现回应。

这意味着:**模块三的训练要求模块二至少到阶段二三**(萌芽期到开花期)。穿透接受还很弱时,模块三的"涌现回应"是空话——没有底层被允许,涌现无处来。

### 模块三和模块二的孪生关系

模块二的"接受"和模块三的"跟随"是孪生的:

- **接受** = 让感受在那里,不修复
- **跟随** = 让回应自然来,不制造

两者本质相同——都是放下控制,允许真实的东西自己出现。

这就是为什么 内在转化理论框架 4.9 末尾说"接受和重新养育的结合"时提到的那种状态——接受底层感受 + 跟随对那个感受的真实回应——这不是两件事,是同一个姿态在感受层和行动层的呈现。

### 模块三的循环

走到阶段四之后,新一轮循环开始:

- 在新的、更微妙的领域,候选盲再次出现
- 旧模式更深的层次浮现,质感识别要在新对象上重建
- 跟随勇气在更大的事上(比如人生重大决定)再次受考验

每次循环不是从零开始——前一轮的能力还在,只是工作的对象换了。

## 五、防滑设计

### 防滑一:不让"做新选择"变成新的强迫

**信号:** "我应该做不一样的""我必须冒险""我又选了旧的我不行"

**应对:** 这就是模块三悖论的具体发作。看到这个念头本身,问自己:这个"应该"的质感是紧的还是松的?如果是紧的,**这不是选择力,是反应模式换了衣服**。停下来。回到候选观察的最低层——只看见,不要求跟随。

### 防滑二:不把"看到选择"当成"必须立刻跟随"

**信号:** 一旦看到候选浮上来,立刻焦虑"我现在应该选新的了"

**应对:** 看见和跟随是两件事。**模块三的大部分训练只在"看见"层面做工作**。看见之后选了旧的,完全 OK——你看见了,就是模块三的工作。下一次看见,你可能跟随,可能不跟随,都正常。**勇气是反复看见之后自然累积的,不是逼出来的。**

### 防滑三:不把质感识别变成新的评判工具

**信号:** "我刚才那个回应是紧的,所以我又错了""我连质感都识别错"

**应对:** 质感识别是观察工具,不是评分工具。**紧的回应不是"错的回应"**——它只是旧模式的回应,告诉你旧模式还在。看到旧模式还在,是有用的信息,不是失败。

### 防滑四:不在急性峰值里做选择训练

**信号:** 一场大爆发中,试图"识别候选 + 跟随涌现"

**应对:** 急性峰值里前额叶掉线,候选辨识和质感识别都暂时下线。**在峰值里做模块三是错的工具**——这时候用工具 A 第二段止血。模块三的工作放到模块二之后(穿透接受到位之后)再做。

### 防滑五:跟随之后结果不好,不撤回

**信号:** 跟随涌现说了真话,对方不开心,你立刻补"算了刚才说的不算"——把跟随撤掉

**应对:** 内在转化理论框架 5.3 明确——冒险的真正价值不在结果,在内在证明"我可以做不同的"。**结果不好不是模块三没练好,是冒险本意如此**。撤回会让大脑学到"原来还是不能跟随"——这比当初没跟随更打击勇气累积。**跟随之后的不舒服,用工具 A 第二段处理(穿透接受不舒服),不用撤回处理。**

### 防滑六:区分臣服和逃避

**信号:** 跟随的"涌现回应"是"什么都不做",事后觉得空虚、压抑、有"我又退缩了"的感觉

**应对:** 这八成不是臣服,是逃避。区分:

- **臣服的质感:** 松、平、不抗;身体不紧;事后没"应该"的残留
- **逃避的质感:** 紧、缩、推开;身体有压;事后有"我应该面对的"残留

如果不确定,问自己:**这个"不行动",是因为我看清了行动无意义,还是因为我害怕行动?** 第一个是臣服,第二个是逃避。逃避不是涌现回应——它是旧模式的一种,不要把它当成模块三的成果。

### 防滑七:不主动寻找冒险机会

**信号:** "我得每天找一件冒险的事来做""今天我没冒险,失败了"

**应对:** 模块三不是"冒险打卡"。**冒险的机会不是被找出来的,是在生活里自然出现**——你被触发时、你穿透接受了之后、那个涌现的回应升起时——那一刻是冒险的机会。**主动制造冒险是另一种形式的反应模式驱动**(被"应该冒险"推着走)。

### 防滑八:允许反复,允许情境化

**信号:** "我在工作上能做新选择,为什么对父母还是讨好"——把这个当退步

**应对:** 选择力高度情境化。在熟悉的安全场景里到了阶段三,在原生家庭面前回到阶段一——这不是退步,是不同情境的训练独立进行。每个情境都要重新走一遍候选辨识 → 质感识别 → 偶尔跟随的循环。

## 六、内在转化理论框架 对应章节

模块三的理论根基:

- **5.3 冒险** —— 选择力的核心理论
- **5.5 母信念第三句话(行动层)** —— "作为成年人对那个小孩说温柔的话"——这是涌现回应的一种形态(对内在小孩的)
- **5.15 接纳/妥协/臣服** —— 涌现回应可以是"不行动"或"允许"的理论支撑;同时为防滑六(臣服 vs 逃避)提供区分基础
- **3.8 反弹四步法** —— 模块三是其中第四步"冒险"
- **4.9 接受(末尾)** —— 接受和跟随的孪生关系

明确不在模块三的:

- **5.5 母信念识别层** —— 是模块一识别力的进阶应用,不是选择层工作
- **4.6 潜意识信念释放** —— 是穿透层(4 章)而不是选择层(5 章)的工作。**明确划在 v3.0 范围之外**——和模块二对 4.6 的处理一致:信念层工作需要更深的资源(一对一陪伴 / 更长周期 / 更专业的方法),不在自助训练系统的边界内。当用户穿透到稳定核心信念时,转介水老师 / 自学 内在转化理论框架 4.6 章节

## 七、Agent 在模块三中的角色

Agent 不是模块三的主角。模块三比模块一二更需要 agent 的克制——**因为模块三的几乎每一种"帮"都可能撞上悖论**。

**Agent 做的:**

- 用户报告"今天看见了选择存在"时,确认看见本身已经是工作(不催促"那你选了什么/为什么没跟随")
- 用户卡在悖论里("我必须做新选择")时,做点破——回到核心定义"选择力不是做新选择的能力,是识别 + 跟随"
- 用户混淆臣服和逃避时,用质感识别帮助区分(防滑六)
- 用户跟随涌现后结果不好、想撤回时,提醒 内在转化理论框架 5.3 的核心——冒险的价值不在结果(防滑五)
- 月度回看时,从工具 C 的记录里看候选辨识频率和跟随稳定度的趋势

**Agent 不做的:**

- **不催促用户跟随涌现的回应** —— "你都看到了,为什么不跟随"是把模块三变成强迫的最快路径
- **不评判用户的具体选择** —— "你这次选得好/不好"——这违反模块三的整个精神
- **不替用户判断哪个候选是涌现的** —— 只有用户自己能感觉质感
- **不在每次对话都问"你今天做了什么不同的"** —— 这就是把"做新选择"变成任务
- **不在用户跟随后追问结果** —— 结果不是模块三的评判标准
- **不在用户被触发的当下推模块三的工作** —— 急性期用工具 A,模块二的工作完成后再考虑模块三

**Agent 在模块三里的核心姿态:** **用户看见了就够了**。剩下的事——跟随不跟随、结果如何、勇气累积多少——交给用户和生活,不交给 agent 的督促。

## 八、未来可能的扩展(v0.2+)

1. **按生存策略分支的冒险方向** —— 这是现状规划 v2 第四部分"待办"里明确的事项。每种生存策略对应不同的核心冒险:
   - 控制型 → 放下控制(让事情如其所是)
   - 讨好型 → 设界限、说不
   - 退缩型 → 表达需求、出现
   - 完美型 → 允许"够好就行"
   - 受害者型 → 承担责任、做选择

   v0.2+ 可以做分支指南——但需要严格警惕"按生存策略给冒险任务"的陷阱(那就是新的反应模式驱动力)
2. **按反弹主导类型分支的选择重点** —— 类似上一条,但维度不同
3. **臣服的独立训练设计** —— v0.1 把臣服作为"涌现回应的一种形态"处理。如果使用反馈显示臣服需要单独的训练路径,v0.2+ 可以拆出独立构件
4. **工具 C 选择层扩展题的具体定稿** —— v0.1 给了方向,具体题号和措辞需要在 v0.2 整合时和工具 C 维护者对照定稿
5. **和水老师一对一工作的集成** —— 重大冒险(辞职、分手、设根本性界限)往往需要陪伴
6. **"评估完成"的显性设计** —— 这是现状规划 v2 待办第 4 条。模块三阶段四之后,如何处理"我练完了吗"的问题。当前的回答是"不存在练完",但这个回答本身需要更系统的处理

以上是 v0.2+ 的事,v0.1 先跑起来。

## 九、最后一句

模块三是 v3.0 三大模块里**最容易被误解、最容易被做反**的模块。

**误解:** 把模块三当成"做新选择的训练"——立刻撞上悖论,变成新的反应模式。

**做反:** 为了"练习冒险"而主动找冒险机会、为了"不撤回"而硬撑结果不好的选择——这都是把模块三当任务在做。

但 内在转化理论框架 5.3 的核心是反直觉的:**真正的冒险不是做出来的,是跟随出来的**。你穿透了底层,接受了感受,在那个位置上,新的回应自然升起——你只需要不再走老路。

模块三要练的不是技巧,是**两个能力 + 一种姿态**:

- **能力一:看见选择存在** —— 候选浮上来
- **能力二:分辨质感** —— 紧的是旧,松的是新
- **姿态:跟随而不强迫** —— 看到松的,就走那条;看到紧的,知道那是旧路不必走;暂时跟不上也没关系,看见了就已经在工作

地基(模块一)有多深,工程(模块二)就能盖多稳。
工程(模块二)有多稳,顶上(模块三)就能多自由。
顶上(模块三)有多自由,反应模式才能真的减少——不是被压抑、不是被取代,是被超越。

但"超越"也不是终点。下一轮循环会从更深处开始——更微妙的反应模式、更深的旧路、更细的辨识。

**v3.0 不存在"练完"。三大模块是一种生活姿态的训练,不是一项任务的完成。**
