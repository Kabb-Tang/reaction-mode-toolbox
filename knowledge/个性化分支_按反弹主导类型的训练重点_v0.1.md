# 个性化分支 · 按反弹主导类型的训练重点(v0.1 初稿)

> **定位:** v3.0 反应模式工作坊的个性化分支之二。给已经在练三大模块的用户(以及辅助他们的 agent)提供按反弹主导类型的训练重点参考——触发时反弹是哪种形态、在三大模块里特别需要注意什么、特定的卡点和防滑。
>
> **核心轴:** 减少反应模式(每种反弹类型在三大模块里都有特别容易卡的地方,精准识别这些卡点比泛泛练习更有效)。
>
> **真正的用户:** Agent(主要)+ 终端用户(次要)。这份资料是三大模块的补充,不是独立训练系统。
>
> **和上一份(按生存策略冒险方向)的关系:** 姊妹篇,但工作角度不同。生存策略是年/十年尺度的整体倾向(主要服务模块三的冒险方向);反弹主导类型是触发时(秒/分钟级)的反弹形态(服务三大模块,但每种类型在不同模块的工作重点不同)。两份资料不互相替代,可同时参考。
>
> **版本状态:** v0.1 初稿。和三大模块 + 理论框架 2.3 (情绪化小孩)一起使用。待使用反馈再迭代。

---

## 一、定位和原则

### 这份资料是什么

理论框架 2.3 区分了情绪化小孩被触发时的五种反弹行为——冲动上瘾、反应过度、习惯性反应、过度期待、责怪受害。理论框架 明确说"大多数人不是只属于一种,而是以某一两种为主,其他偶尔出现"——这就是"反弹主导类型"概念的来源。

每种反弹主导类型在三大模块里都有**特别容易卡的地方**,也有**特别需要重点训练的环节**。这份资料把这些重点显性化:**按用户的反弹主导类型,提供"在三大模块里你特别需要注意 X / 容易卡在 Y / 防滑要点是 Z"的参考**。

### 这份资料不是什么

(关于"不是分类系统/不是任务清单/不是诊断输出"的基础原则,在《按生存策略的冒险方向》第一部分已立住。这一份直接承接,不再展开。)

唯一需要在这里强调的是:**反弹主导类型不是给用户贴的标签**。它是 agent 在对话中识别"这次触发用户走的是哪种反弹形态"的工作视角,服务于精准训练,不服务于身份归类。

### 这份资料和三大模块的关系

| 模块 | 这份资料的工作 |
|---|---|
| 模块一(识别力) | 不同反弹类型有不同的早期信号,识别的入口不同 |
| 模块二(穿透力) | 不同反弹类型穿透到的底层感受不同(理论框架 2.3 的五种底层感受),穿透路径有差异 |
| 模块三(选择力) | 不同反弹类型的"涌现回应方向"和生存策略层是不同维度——更具体到"触发时怎么打断旧反弹形态" |

注意:**模块三的冒险方向参考是上一份(按生存策略)处理的,这一份不重做模块三的整体冒险**——这一份在模块三层面只处理"触发时如何打断特定反弹形态"这种**急性版**的选择工作。

## 二、五种反弹主导类型

下面五种反弹主导类型各自展开。每节结构:**发作信号 / 底层感受 / 在三大模块中的特别工作重点 / 特定卡点和防滑**。

每节末尾点明一句:**这些是描述,不是清单**。

---

### 2.1 冲动上瘾型

#### 发作信号

- 触发时立刻"必须"做一个具体动作:吃、喝、买、刷手机、找人发消息、打开某个 app、抽烟、性等
- 有"不做不行"的急迫感,无法停下来
- 做完之后短暂缓解,然后空虚或自责
- 行为有逐渐升级的剂量(以前 10 分钟够,现在 1 小时不够)
- 不能单独静坐——15 分钟不做事就难以忍受
- 自己知道这个行为对自己没好处,但停不下来

(参见 理论框架 4.7 上瘾行为识别信号)

#### 底层感受

冲动上瘾型最常逃避的是 **空虚** 和 **焦虑**(理论框架 2.3 五种底层感受)。少数情况是 **恐惧**——存在性的"如果我停下来我会塌掉"。

冲动上瘾的本质不是对某物上瘾,是**对"回避内在感受"上瘾**(理论框架 4.7)。

#### 在三大模块中的特别工作重点

**在模块一(识别力)中:**

冲动上瘾型的关键识别信号是 **"我又想 X 了" 那一瞬**——而不是已经在做 X 的过程中。

很多冲动上瘾用户的识别力卡在"已经做完才意识到"。模块一的训练对这个类型特别需要往前推一步——**识别"想做"的冲动升起的那一秒**,而不是只识别行为本身。

具体做法:工具 C 月度回看时,专门追踪"我做这个 X 之前几秒,我感觉到了什么?"——慢慢把识别推到行为之前。

**在模块二(穿透力)中:**

冲动上瘾型的核心穿透问句是 理论框架 4.7 的核心问句:

> "如果我现在不[做那个上瘾行为],我会感到什么?"

这个问句直接指向上瘾正在逃避的东西。冲动上瘾用户做工具 A 第二段或日常深潜接受时,可以把这句作为下潜的入口。

**在模块三(选择力)中:**

冲动上瘾型的"急性版选择工作"是 理论框架 4.7 阶段二的"在想做的瞬间停 10 秒":

- 不强迫自己不做(那是意志力对抗,通常失败)
- 只是停 10 秒
- 在这 10 秒里问"如果我不做,我会感到什么"
- 然后选择做或不做都行

**关键:不追求"我从此不上瘾",追求的是"想做的瞬间能停一下"**。停一下本身就是选择的入口——做不做反而是次要的。

#### 特定卡点和防滑

- **意志力对抗陷阱:** 用"我不能再这样"来戒——这通常失败。理论框架 4.7 明确:这是"用同一个系统试图解决这个系统制造的问题"。识别到自己在意志力对抗时,转向"看见自己在逃避什么"
- **替代瘾陷阱:** 戒了一个上瘾,变成另一个(戒了刷手机变成暴食,戒了暴食变成购物)。这是同一个机制换载体。识别这个,而不是继续戒
- **不能"突然不做"的接受:** 阶段一(看见)和阶段二(停 10 秒)可能持续很久。**反弹后的恢复速度,比"不反弹"更有意义**(理论框架 4.7)。今天没停下来,明天还可以再练
- **关系上瘾的隐蔽性:** 理论框架 4.7 提到的"关系上瘾"(必须有人在身边、立刻开始下一段关系、纠缠不适合的人)在自我识别时常被错认为"深情""痴情"。识别信号是"我离开这个人感到崩溃"——崩溃 ≠ 难过,崩溃指向上瘾机制
- **不主动制造戒断挑战:** 这是上一份(按生存策略)防滑七的延伸——不主动制造痛苦练习接受。冲动上瘾型用户可能想"那我每天少刷 1 小时手机"——这立刻撞模块二防滑七。日常已有的冲动够练,不需要加码

**这些是描述,不是清单**。

### 2.2 反应过度型

#### 发作信号

- 客观上小事引发不成比例的大反应(伴侣忘买牛奶 → 暴怒;同事一个眼神 → 一整天低落)
- 反应强度和事件不匹配——旁人觉得"至于吗",自己事后也"刚才怎么那样"
- 反应在身体上常常很强烈(发抖、心跳加速、突然哭泣)
- 反应过去之后常常觉得羞耻或自责
- 别人的小动作能在你身上产生持久的内在波动
- 经常被告知"你太敏感了"

#### 底层感受

反应过度型反弹底下最常见的是 **悲伤** 或 **恐惧**(理论框架 2.3 五种底层感受)——不匹配的反应强度,标志着触发的不是当下事件,是被激活的老伤口。

具体来说:伴侣忘买牛奶背后可能是"我又被忽视了/我对你不重要"(被忽视的悲伤);同事眼神背后可能是"我又被评判了/我有问题"(羞耻的恐惧)。

#### 在三大模块中的特别工作重点

**在模块一(识别力)中:**

反应过度型的关键识别工作是 **识别"反应强度不匹配"本身就是信号**——而不是把反应当成事件本身的合理回应。

很多反应过度用户卡在"我觉得我反应是合理的,他确实做错了"——把反应正当化。模块一的训练对这个类型需要特别引入"强度不匹配"作为识别工具:

> 当我的反应强度,明显超过这件事在客观上的分量时,我就在被激活的老伤口里——而不是在处理当下的事。

工具 C 的反应日志里,反应过度型可以专门记录"事件客观分量 × 我的反应强度"——慢慢看到模式。

**在模块二(穿透力)中:**

反应过度型的核心穿透方向是 **从当下事件穿透到老伤口**(理论框架 2.15 触发点 vs 源头)。

具体做法:在工具 A 第二段的深潜段,反应过度用户可以加一个特别的提问:

> "这个反应强度,让我想到了过去什么样的时刻?"

这个问题不是要"解释"反应,是在感受层面接通——身体里这个反应的质感,在过去某个相似的时刻被同样唤起过。穿透到那个时刻的核心感受。

注意:这不等于"挖出童年原因"——目的不是解释,是**让被激活的旧感受被允许在场,而不是被当成对当下事件的合理回应继续行动**。

**在模块三(选择力)中:**

反应过度型的"急性版选择工作"是 **在反应升起时不立刻做反应所驱动的行动**:

- 反应升起 → 识别"这是被激活,不只是当下事件"
- 不立刻按反应行动(不立刻发那条消息、不立刻吵那一架、不立刻摔门)
- 不是压抑——感受可以在身体里炸开
- **只是不立刻把感受变成对当下他人的行动**

如果可以的话,稍后用工具 A 第二段处理这个反应。如果不行,过一段时间再以平稳的状态回到事件本身。

#### 特定卡点和防滑

- **正当化陷阱:** "我反应大是因为他真的做得太过分了"——把反应正当化掉。识别"强度不匹配"本身就是工作,不是否定事件
- **羞耻反弹陷阱:** 反应过去后强烈羞耻("我怎么又这样")——羞耻本身又激活新一轮反应过度,循环。模块二的接受工作要把"反应过去后的羞耻"也作为接受对象,而不是另一个要消除的问题
- **挖掘童年陷阱:** 反应过度型的穿透容易变成"找出每次反应对应的童年事件"——理论框架 4.5 障碍三说理性化是问题。穿透是感受层面的,不是历史考古
- **过度敏感叙事的陷阱:** 反应过度型常常被告知"你太敏感了",可能内化成"敏感是我的问题"——这是把反弹模式当身份。模块三的工作不是变得"不敏感",是让被激活的旧感受不再驱动当下的行动
- **不要在峰值期处理:** 反应过度型在反应峰值时容易被自己的强度吞没——任何穿透/选择工作都做不了。先用工具 A 第一段止血,峰值过去再做第二段

**这些是描述,不是清单**。

### 2.3 习惯性反应型

#### 发作信号

- 在类似情境里反复做同样的反应——自己都能预测
- "我就是这样,每次到 X 我就会 Y"
- 不同关系里反复上演同样的剧本(每段亲密关系都以同样方式破裂、每个工作都以同样方式离开、每次冲突都按同样剧本走)
- 反应是"自动的"——感觉不到"反应"的过程,直接出结果
- 这个模式被自己接受为"性格"——"我就是这种人"
- 改变的尝试常常很短暂,然后回到旧模式

#### 底层感受

习惯性反应型底下最常见的是 **不信任** 和 **自卑**(理论框架 2.3 五种底层感受)。

不信任表现为:习惯性预设"反正最后会 X"(被辜负、不被理解、关系会破裂)——这种预设本身让人按预设的方式行动,导致预言自我实现。

自卑表现为:习惯性反应是"我这种人就是这样"的延续——内在深信自己有某种根本性的缺陷,所以反复回到证明这个缺陷的位置。

#### 在三大模块中的特别工作重点

**在模块一(识别力)中:**

习惯性反应型的关键识别工作是 **识别"自动化"本身**——而不是只识别反应内容。

习惯性反应的最大隐蔽是它已经被接受为"性格",所以连"这是反应"的意识都没有。模块一的训练对这个类型需要特别建立"自动 = 反应"的识别:

> 任何在我身上自动发生的、可预测的行为模式,都是反弹模式的一种——哪怕它感觉就是"我"。

工具 C 月度回看时,习惯性反应用户可以专门追踪:"这个月我有哪些行为模式是被自己预测到了的?"——把"我就是这样"的句式列出来,每一句都可能是一个被固化的反弹模式。

**在模块二(穿透力)中:**

习惯性反应型穿透特别困难——因为反应是自动的,你常常感觉不到"反应"在升起,直接看到结果。

这种类型的穿透需要 **慢动作工作**:事后回看那个自动模式,在脑子里把它"慢放":

- 那次自动反应之前,身体上发生了什么(就在自动反应升起前的几秒)
- 那一瞬间,有什么东西被勾起了
- 在那个被勾起的位置,是什么感受

这种慢动作回看就是穿透——把自动化拆解成可以下潜的层次。

**在模块三(选择力)中:**

习惯性反应型的"急性版选择工作"特别难,因为自动化让"看到选择"几乎不可能。

这种类型的选择工作要**先在事后建立**:

- 在自动反应发生之后,事后看清"如果当时我不是自动那样,我可能选什么?"
- 不是要求当下做不同选择(短期内可能做不到),是建立"这个自动模式不是唯一可能"的内在认知

随着模块一二的工作进展,自动化会逐渐松动——选择的空间在自动化的缝隙里慢慢出现。这个过程很慢,不要追求短期突破。

#### 特定卡点和防滑

- **"性格"陷阱:** "我就是这种人"——这是 理论框架 2.3 明确指出的危险("一旦你接受这个标签,模式就被固化了,你不再问'为什么'")。模块一的工作就是反复打破"性格"叙事
- **改变焦虑陷阱:** 习惯性反应型尝试改变时常常体验到强烈不安(因为旧模式底下藏着的是不信任/自卑——改变意味着进入未知)。这个不安要被识别为旧模式的最后防御,不是"改变是错的"的证据
- **预言自我实现陷阱:** 习惯性反应型特别容易在亲密关系里反复印证"反正会失败"——他/她按"会失败"的方式行动,然后真的失败,然后强化"我就说嘛"。这种循环要在模块三里特别警觉,但不能用"我必须打破循环"的强迫去破(撞悖论)
- **慢就是常态:** 习惯性反应型的训练进步特别慢——因为对象是已经被"性格化"的反应。**不要追求快速突破。慢就是这种类型的常态。**

**这些是描述,不是清单**。

### 2.4 过度期待型

#### 发作信号

- 对别人/关系/生活有"理所当然"的要求——他应该懂我、她应该记得、他们应该尊重我
- 期待没被满足时强烈愤怒或受伤
- 反复在关系里失望——每段关系都以"对方让我失望"结束
- 不直接表达期待(因为"如果他爱我他就应该知道")
- 别人按期待行动时短暂满足,马上有新的期待
- "应该"这个词在内在叙事里频率极高

#### 底层感受

过度期待型底下最常见的是 **悲伤** 和 **被剥夺感**(理论框架 2.3 五种底层感受 + 2.5 核心创伤)。

理论框架 2.3 明确:**期待的本质是把童年没被满足的需求,移植到成年关系中**(理论框架 1.11 引用)。"你以为你在要求合理的事,其实你在等那个小时候没来的大人终于出现。"

底层感受是:那个小时候没被满足的需求带来的悲伤 + 被剥夺感。期待的反复发作和反复失望,是这个原始悲伤反复被激活又反复被埋藏。

#### 在三大模块中的特别工作重点

**在模块一(识别力)中:**

过度期待型的关键识别工作是 **识别"应该"那个词**——以及它所标记的隐性期待。

过度期待用户的"应该"常常是隐性的——"他应该懂我"不被说出来,但每次他没懂,反应就会发作。模块一的训练对这个类型需要特别引入"应该的识别":

> 当我对一件事或一个人有强烈反应时,先问自己:我对此有一个隐性的"应该"吗?

工具 C 的反应日志里可以专门记录:"这次反应背后,我有一个什么'应该'?"——把隐性期待显性化。

**在模块二(穿透力)中:**

过度期待型的核心穿透方向是 **从"他应该 X"穿透到"小时候我需要 X 但没得到"**——理论框架 2.15 触发点 vs 源头的具体应用。

具体做法:在期待破灭后的反应里,工具 A 第二段的深潜段可以加这个提问:

> "如果当下不是 Y(伴侣/同事/朋友)让我失望,而是回到很早,有谁/有什么事让我有过同样的失望?"

下潜到那个原始的失望——通常是早年某个具体场景或弥散的感觉。然后做接受工作:那个失望可以在那里。

注意:这不等于"原谅父母"或"理解过去"——目的不是认知重构,是**让原始的悲伤被允许在场,从而停止在当下关系里反复演**。

**在模块三(选择力)中:**

过度期待型的"急性版选择工作"是 **直接表达需求,而不是期待对方"看出来"**:

- 识别到自己对某事有期待
- 不等对方"应该懂"
- **直接说出来**——"我希望你 X""我需要你 Y"
- 接受对方可能不答应——这是涌现的回应,是模块三的冒险

这一项和"按生存策略冒险方向"里讨好型的"表达需求"有交集——但角度不同。讨好型是"长期不表达需求的整体倾向";过度期待型是"在每次期待发作时,把期待显性化为请求"。

#### 特定卡点和防滑

- **直接表达后被拒绝的痛:** 过度期待型一旦开始直接表达,会暴露出"被拒绝"的痛——这一直是隐性期待在保护用户不直面的。这个痛是真实的,需要工具 A 第二段处理,不是"直接表达是错的"的证据
- **从过度期待到不再期待的反弹:** 过度期待型在工作初期容易反弹到另一个极端——"那我以后什么都不期待了"。这是退缩型的混入,不是模块二三工作的目标。**健康的位置是:期待清晰、表达直接、接受可能不被满足**——不是消除期待
- **要求对方做模块三的工作:** 过度期待型可能把"他应该懂我的反应模式""他应该配合我的训练"作为新的期待——把训练本身变成新的应该。识别这个
- **挖掘原始失望的危险:** 穿透到原始失望时,可能涌出强烈的悲伤——如果到了无法承受的程度,转介工具 B 状态判断,必要时找水老师线下工作

**这些是描述,不是清单**。

### 2.5 责怪受害型

#### 发作信号

- 痛苦发生时第一反应是找人负责
- 指向外部:"都是他的错""如果不是因为 X……"
- 指向自己:"都是我不好""我就不该……"——表面相反,本质同
- 把自己放在无法行动的位置
- 反复在关系里"被亏待""被辜负"
- 别人指出自己的责任时强烈防御
- 受害叙事详细丰富、能反复讲述

#### 底层感受

责怪受害型底下最常见的是 **不信任** 和 **悲伤**(理论框架 2.3 五种底层感受)。

不信任的形式是:"反正没人会帮我/没人会公平对我/世界就是亏待我的"——这种预设让用户始终在受害位置。

悲伤的形式是:童年真的有过被剥夺、不公平、无力的经历(理论框架 2.5 核心创伤的"被剥夺")——这个原始悲伤在每次责怪受害的发作里被激活又被掩盖。

#### 在三大模块中的特别工作重点

**在模块一(识别力)中:**

责怪受害型的关键识别工作是 **识别"找责任"这个动作本身**——而不是停留在"谁的错"的内容上。

责怪受害型的反应内容(谁错了)常常占据所有意识,模块一的训练对这个类型需要把识别的对象从"内容"提升到"模式":

> 当我感到痛苦时,我的第一动作是不是在找谁负责?(指向外或指向自己,都算)

工具 C 的反应日志里可以专门记录:"这次反应里,我把责任归给了谁?"——慢慢把"找责任"作为一个可识别的反弹模式,而不是合理的认知活动。

**在模块二(穿透力)中:**

责怪受害型穿透的特别难点:**找责任这个动作本身就是逃避底层感受的方式**——只要还在"谁错了"的层面,就不会下到底层悲伤。

这种类型的穿透需要 **跳过"找责任"层,直接问感受**:

- 不问"谁错了"——这个问题永远有答案,而且答案会让人停在表层
- 直接问:"如果不去问谁对谁错,我现在身体里/心里的感受是什么?"
- 通常会下到一种无力感或悲伤
- 在这个感受里待着——理论框架 2.5 被剥夺感的接受工作

注意:这不是说"事件中没有谁错"——可能确实有错的一方。但**模块二的工作不是裁判,是接受底层感受**。错对的事可以在另一个层面处理(比如真的需要法律行动、需要离开关系等),但模块二的工作不依赖这个。

**在模块三(选择力)中:**

责怪受害型的"急性版选择工作"是 **从"谁的错"切到"现在我能做的小事是什么"**:

- 识别到自己在找责任
- 暂停找责任的循环
- 问:"在这件事里,现在我能做的最小的一件事是什么?"
- 做那件事——哪怕很小

这是 理论框架 5.3 冒险的"承担责任"维度,但要避免变成"我必须承担一切责任"(那是从受害者反弹到自责的另一种受害者位置)。

健康的位置:**这件事里我能做的小事是 X,我去做。其他不在我控制的部分,允许它在那里**。

#### 特定卡点和防滑

- **找责任正当化:** 责怪受害型的反应常常事实层面合理("他确实不对")——但事实层面的合理不等于反弹模式不在工作。识别"我又在找责任"和"他是不是真的错了"是两个层面的事
- **从受害反弹到自责的循环:** "都是我不好"看起来是承担责任,实际是把自己当成新的受害对象(自己受害自己)。模块三的工作要警惕这个反弹
- **受害叙事的获益:** 受害位置有隐性好处(不用负责任、获得同情、避免冒险)。识别这些获益不是为了羞辱用户,是为了让用户有意识地选择是否继续在这个位置上
- **"理解 ≠ 解除责任":** 这是上一份(按生存策略)受害者型已经点过的关键。在反弹主导版的责怪受害型上同样适用——理解童年经历(理论框架 2.5)是为了改变模式,不是为了把当下的反弹正当化
- **不要急于"我从此不抱怨"或"我从此承担一切":** 这两种都是反弹的极端形式。一次具体场景里识别"这次找责任是反弹",在那个具体场景里换一种回应——这才是工作

**这些是描述,不是清单**。

## 三、混合型 + 和生存策略的关系

### 大部分人是混合型反弹

理论框架 2.3 已经明确:大多数人不是只属于一种,而是以某一两种为主,其他偶尔出现。

常见组合:
- **冲动上瘾 + 反应过度**(用上瘾行为缓解反应过度的强度)
- **过度期待 + 责怪受害**(期待没满足 → 找谁负责)
- **习惯性反应 + 责怪受害**(同样的剧本里反复找同样的责任人)
- **冲动上瘾 + 习惯性反应**(同样的触发 → 同样的上瘾行为)

混合型的处理:**根据当下场景识别哪种主导**。一次触发可能先反应过度,然后冲动上瘾;另一次触发可能先过度期待,然后责怪受害。每次都看当下走的是哪条。

### 反弹主导类型 × 生存策略

(关于两者时间尺度的区分,在前文"和上一份的关系"已说明。)

实际工作中,两者交叉。常见组合:

| 生存策略 | 容易共生的反弹主导类型 |
|---|---|
| 控制型 | 反应过度(失控时) + 责怪受害(被违逆时) |
| 讨好型 | 冲动上瘾(逃避被冒犯/委屈) + 过度期待(隐性) |
| 退缩型 | 冲动上瘾(逃避亲密) + 习惯性反应(每次都撤回) |
| 完美主义型 | 反应过度(被指错) + 责怪受害(指向自己) |
| 受害者型 | 责怪受害(主导) + 过度期待(隐性) |

**v0.1 不展开 25 种组合的工作指南**——会膨胀失控。Agent 在对话中根据用户当下的具体形态判断,这两份资料各自查阅参考,不需要预先固化交叉表。

v0.2+ 如果使用反馈显示需要,可以做更详细的交叉指南(见第六部分)。

### 同一个用户在不同模块进度上的反弹差异

随着三大模块的工作深入,反弹形态也会变化:

- 模块一到位前:反弹自动且快速
- 模块一到位后:能看见反弹但还是在反弹
- 模块二到位后:反弹后能穿透,频率开始减
- 模块三开始工作后:反弹时偶尔能停一下

这意味着 agent 在使用这份资料时,要参考用户**当下**的反弹形态,而不是用户"历史上的反弹主导"。

## 四、Agent 如何使用这份资料

### Agent 何时使用

- 用户描述一次具体的触发-反弹经历——agent 可以根据反弹形态识别主导类型,引向对应资料
- 用户问"我在 X 模块里特别卡 Y"——agent 可以查阅对应反弹主导类型在那个模块的特别重点
- 用户的训练长期没有进展——agent 可以审视是否漏掉了反弹主导类型对应的特别工作重点

### Agent 怎么用

- **不输出反弹类型标签作为身份**:不说"你是冲动上瘾型"。说"听起来这次的反弹形态有冲动上瘾的特征"——把反弹形态当工作对象,不当身份
- **从用户的具体描述识别**,不主动测试。用户一次触发的具体描述里,反弹形态通常很清楚
- **混合型时根据当下场景判断主导**,不强行归类
- **资料的引入是按需的**,不是上来就推。用户没问起的时候不主动套反弹类型框架

### Agent 不做的事

- **不主动给用户做"反弹类型测试"**——v3.0 不做诊断式分类
- **不在每次反弹描述后都套类型**——大部分反弹描述需要的是陪伴和工具引导,不是分类
- **不把"按反弹类型练 X"做成任务**——所有训练重点都是参考方向,不是必做项
- **不替用户判断他的反弹主导类型**——只有用户自己反复回看后能看清

### 一个具体的对话姿态

用户:"我又对老婆吼了一顿,因为她忘了倒垃圾。我知道这事很小,但我当时就是控制不住。"

不要说: "你这是反应过度型,你应该练习识别强度不匹配。"

可以说: "听起来事件本身的分量(忘倒垃圾)和你的反应强度(吼一顿)不匹配——这种'不匹配'本身就是一个信号:被激活的可能不是这件事,是某个老伤口被勾起了。这种'反应过度'的形态在 理论框架 里有专门的描述,如果你想看一下它在三大模块里的特别工作重点,我可以发给你。"

第二种说法的区别:**描述形态,不贴标签;指向工作方向,不下命令**。

## 七、最后一句

这份资料的核心工作是:**把"五种反弹"从抽象概念变成针对每种类型的具体训练重点**。

它不是给用户分类用的,是让训练精准用的。

冲动上瘾型在模块一最需要往前推一秒(识别"想做"那一瞬);反应过度型在模块二最需要"强度不匹配 = 老伤口"的接通;习惯性反应型在模块三需要慢动作工作而不是快速突破;过度期待型需要把隐性"应该"显性化;责怪受害型需要跳过"找责任"层直接到底层感受。

这些是不同类型在不同模块里的不同重点——而不是"五种类型 × 三大模块 = 15 种训练任务"。**精准训练,不是覆盖训练**。

每种反弹类型都有它的固化路径,也有它的松动入口。

模块一让你看见反弹形态;模块二让底层感受流动;模块三让自动化的反弹有机会被打断。这份资料让这三件事在你的具体反弹形态上更精准地发生。

但走多远、什么时候走、怎么走——交给用户和生活。
